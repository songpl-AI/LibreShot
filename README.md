# LibreShot

[中文](README.md) | [English](README_EN.md)

LibreShot 是一款轻量、现代化的 macOS 截图与标注工具，原生开发，完全免费开源。

最新公开版本：[v1.3.5](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.5) · [更新说明](docs/releases/1.3.5.md) · [更新日志](CHANGELOG.md)

## ✨ 特性

- **极简设计**：原生 macOS 风格，轻量快速，完美融入系统。
- **丰富的标注工具**：
  - 🖊️ **画笔**：自由绘制。
  - ⬜ **矩形/椭圆**：快速框选重点。
  - ↖️ **箭头**：精准指向。
  - 📝 **文字**：内联所见即所得编辑，支持多行、字号与颜色。
  - 🔢 **序号标注**：带圆圈的自动递增数字，指引关注点。
  - 💧 **模糊/马赛克**：轻松隐藏敏感信息（如人脸、账号）。
- **OCR 文字识别 + 翻译**：内置离线 OCR 引擎，一键提取截图中的文字（支持中英文），并可在安装语言包后离线翻译（macOS 26+，首次下载语言包需要联网）。
- **在原图位置翻译**：在截图原来的文字位置显示译文，可逐段校正、切换原图、复制、保存或继续标注（macOS 26+）。更适合纯色背景的文档和界面；复杂背景不保证无痕还原。
- **长截图**：支持滚动长截图，默认进入可滚动、缩放的标注窗口；也可在设置中改为预览后复制或保存。
- **自动保存**：区域截图点击 ✅ 时复制到剪贴板，开启自动保存后同时保存到指定目录；也支持手动「另存为」。
- **自定义工具栏**：在设置中勾选显示或隐藏工具按钮，拖动工具行或用上下箭头调整顺序；已启用工具直接显示，窄窗口自动换行，不另设“更多”菜单。
- **贴图置顶**：支持将截图“钉”在屏幕最上层，方便对照参考或跨应用协作。
- **快捷键支持**：可自定义全局截图和编辑工具快捷键；可选双击 Option 启动区域截图，以及空格完成或保存并复制。
- **本机处理**：截图、OCR 和翻译文本在本机处理；首次下载翻译语言包、检查更新需要联网。
- **完全免费**：开源自由，打破收费壁垒。

## 📦 安装

### 方式一：GitHub Releases (推荐)

> 💻 **系统要求**：macOS 13.0 (Ventura) 及以上版本。

1. 前往 [Releases](https://github.com/songpl-AI/LibreShot/releases) 页面下载最新的 `.dmg` 安装包。
2. 双击打开 `.dmg` 文件，将 `LibreShot.app` 拖入 `Applications` 文件夹。

升级时先退出 LibreShot，再用新版本替换“应用程序”中的旧版本；已有工具栏和保存设置会保留。安装包同时支持 Apple Silicon 与 Intel，翻译功能需要 macOS 26+。

GitHub 安装包使用 ad-hoc 签名，未经过 Apple 公证，因此 macOS 默认可能阻止直接打开。请只从本仓库 Release 下载，先用附件 `SHA256SUMS` 校验，再按 [Apple 官方的打开 App 指引](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中确认；不要全局关闭 Gatekeeper。若提示文件损坏，先重新下载并核对校验值。此包不等同于 Developer ID 签名、公证后的免提示安装包。

首次截图需要在“系统设置 → 隐私与安全性”中允许 LibreShot 录制屏幕（该项目在不同系统版本中可能叫“屏幕录制”或“录屏与系统录音”）。双击 Option 还需“输入监控”权限。升级临时签名版本后，macOS 可能要求重新授予这两项权限，并退出、重新打开 LibreShot。

升级后即使授权开关已开启，也可能仍绑定旧包：先退出 LibreShot，在对应权限页移除旧项，再用“+”添加 `/Applications/LibreShot.app`，开启后重新打开。屏幕录制与输入监控要分别检查，完成一次实际截图和保存，再重启复验。维护者每次新包必须执行 [安装与授权验收规范](docs/operations/install-and-permissions.md)。

### 方式二：自行构建

如果您是开发者，可以自行编译源码：

```bash
# 1. 克隆代码
git clone https://github.com/songpl-AI/LibreShot.git

# 2. 打开项目
cd LibreShot
open LibreShot/LibreShot.xcodeproj

# 3. 使用 Xcode 编译并运行 (Cmd + R)
```
*当前源码使用 macOS 26 SDK，请使用 Xcode 26 或更新版本；应用部署目标为 macOS 13.0。*

GitHub 分发默认使用 ad-hoc 签名：运行 `bash build_release.sh`，也可显式指定 `--ad-hoc`。每次更新后可能要重新授予录屏和输入监控权限；此安装包不能提交 Apple 公证。若将来配置了 Developer ID Application 证书，可显式运行 `bash build_release.sh --developer-id`。脚本会核对签名模式，不自动公证或上传。测试说明见 [tests/README.md](tests/README.md)，本次修复见 [1.3.5 更新说明](docs/releases/1.3.5.md)。

## 🚀 使用指南

截图框选完成后出厂默认使用“选择/移动”；可在工具栏设置中选择其他默认标注工具。1.3.4 修复不规则笔迹选框并减少轻点抖动误操作。

### 1. 快捷键启动 (推荐)
- **区域截图**：默认快捷键 `Cmd + Shift + X`
- **全屏截图**：默认快捷键 `Cmd + Shift + A`

前往 **设置** 可随时自定义这些快捷键。这是最高效的使用方式。

### 2. 菜单栏启动
点击顶部菜单栏的“剪刀”图标，选择相应功能：
- **区域截图**
- **全屏截图**
- **长截图**

*(注：菜单项旁边会自动显示当前绑定的全局快捷键，方便随时查看)*

### 3. 标注与编辑


**1.3.3 更新**：马赛克标注新增八向缩放控制点和悬停光标，取消选中时的额外蓝框；支持撤销调整。详见 [更新说明](docs/releases/1.3.3.md)。

**1.3.2 更新**：单击不再产生无效图形；画完矩形、椭圆或箭头立即显示圆形控制点，选中旧标注后保留对应工具，可在空白处继续绘制。拖动已选中标注可移动，箭头可分别调整首尾。按 Delete/Backspace 删除选中项，⌘Z 撤销删除或调整；文字输入时删除键仍用于输入。选区圆角预览与输出保持一致。工具快捷键已移至“工具栏”页对应排序行，空格动作仍在“快捷键”页。验证记录见 [本次修复验收](docs/qa/issue-9-20261002.md)。

**1.2.0 新增**：启用任意标注工具时，点一下已有标注即可选中；矩形、椭圆请点边框，避免把内部空白误认为图形。选中后可拖动移动；矩形、椭圆还会显示八个蓝色控制点，拖动角点或边中点可缩放，拖动内部空白也能移动。外层白色控制点调整的是截图范围。直接按住拖动仍按当前工具绘制新标注；文字仍支持双击编辑。

**1.3.5 更新**：支持配置截图后的默认工具、双击序号改号，以及序号缩放和大小/颜色继承。详见 [更新说明](docs/releases/1.3.5.md)。

框选截图范围后，会自动进入编辑模式，四角和四边中点立即显示可拖动的控制点，可直接调整截图范围。按一次 `Esc` 即可取消当前截图（包括正在输入文字时；编辑序号时先取消改号，再按一次取消截图）；点击“选择/移动”或再次点击当前工具可切回选择模式。浮动工具栏提供以下功能：
- **形状工具**：点击矩形、圆形或箭头图标进行标注。
- **序号标注**：点击序号图标，点一下即放置一个带圆圈的自动递增数字。双击已有序号可输入 1–9999，回车确认、Esc 取消改号；改为 N 后下一编号为 N+1。选中后拖动右下角手柄缩放，后续序号继承大小和颜色。删除最近创建或改号的序号可回退下一编号，删除中间项不重排其他编号；⌘Z 可撤销。
- **马赛克/模糊**：选择对应工具，框选需要打码的区域；鼠标停在按钮上可查看工具名称。
- **文字工具**：点击 "T" 图标，在图上点一下就地输入，所见即所得；回车换行，点空白处提交。
- **颜色与字号**：点击工具栏红、黄、蓝、绿组成的四格色板，弹出面板选择颜色（预设色板 + 系统取色器）与字号；色板下方细色条表示当前颜色。选中文字后拖拽右下角手柄可等比缩放字号。

### 4. 贴图 (Pin)
点击工具栏上的 **📌 (图钉)** 图标，当前截图将以悬浮窗口形式固定在屏幕最上层。您可以随意拖动它，双击即可关闭。这在对比代码、参考资料时非常有用。

### 5. 长截图
点击工具栏上的 **长截图** 图标，按提示先框选目标区域，然后滚动页面内容：
- **开始方式**：可从菜单栏选择“长截图”，或在区域截图编辑工具栏中点击长截图图标。
- **使用流程**：框选目标区域后开始滚动，完成后按回车结束，按 `Esc` 可取消。
- **结果处理**：默认进入可滚动、缩放的标注窗口；可在设置中关闭“完成后进入标注编辑”，改为预览后选择复制或保存。开启自动保存时保存到预设目录，否则显示保存面板；“另存为”始终显示保存面板。

### 6. OCR 文字识别与翻译
点击工具栏上的 **OCR** 图标，软件将自动识别截图中的文字，并弹窗显示识别结果，支持一键复制；在结果窗口中还可选择目标语言进行离线翻译（macOS 26+）。首次使用若缺少语言包，系统会提示下载免费的语言包；确认后需联网下载，已安装的语言直接翻译。取消后可以再次点击翻译重试。也可在“系统设置 → 通用 → 语言与地区 → 翻译语言”管理语言包。已确认的下载可能由系统在后台继续。

点击 **原图翻译** 可把译文放回截图对应的文字区域，支持修改单个译文、切换原图与译图、复制、保存和继续标注。译文过长时需缩短或取消勾选该区域后才能导出。相邻段落行会尽量保持一致字号；复杂底纹、表格和特殊字体仍可能需要人工检查。

### 7. 设置
在菜单栏点击剪刀图标选择“设置...”，或在 LibreShot 激活时按 `Cmd + ,`，可以：
- **设置快捷键**：自定义“区域截图”和“全屏截图”的全局快捷键。
- **编辑快捷键**：为标注工具设置按键；默认 ⌘S 保存、⇧⌘S 另存为、回车完成、⌘Z 撤销。文字输入期间普通字符、空格和回车仍用于输入；序号编辑期间数字用于输入、回车提交、`Esc` 取消改号，其他情况下 `Esc` 取消截图。
- **双击 Option**：可选开启区域截图手势，需在系统设置授予输入监控权限；按键组合、长按或夹杂鼠标操作不会触发。
- **空格动作**：可选关闭（默认）、完成、保存并复制。“完成”遵循自动保存设置；“保存并复制”始终写入预设目录，保存失败仍保留剪贴板。
- **保存路径**：自定义截图文件的默认保存位置。
- **自动保存**：开启后，区域截图点击 ✅ 会同时复制和保存；关闭后 ✅ 只复制。保存失败会提示，截图仍保留在剪贴板。
- **工具栏**：勾选显示或隐藏按钮，拖动工具行或点击上下箭头排序；隐藏的工具保留原位置，完成和取消可排序但始终显示。配置自动保存，从下一次截图开始生效；“恢复默认”同时恢复全部按钮、默认顺序和默认工具。可选择截图后的默认工具，出厂为选择/移动；隐藏已设为默认的工具后回退选择模式；隐藏选择按钮后，可再次点击当前工具切回选择模式。`Esc` 取消截图，序号编辑期间先取消改号。
- **启动设置**：设置是否开机自启。
