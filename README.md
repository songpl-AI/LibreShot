# LibreShot

[中文](README.md) | [English](README_EN.md)

LibreShot 是一款轻量、现代化的 macOS 截图与标注工具，原生开发，完全免费开源。

## ✨ 特性

- **极简设计**：原生 macOS 风格，轻量快速，完美融入系统。
- **丰富的标注工具**：
  - 🖊️ **画笔**：自由绘制。
  - ⬜ **矩形/椭圆**：快速框选重点。
  - ↖️ **箭头**：精准指向。
  - 📝 **文字**：添加文本说明。
  - 💧 **模糊/马赛克**：轻松隐藏敏感信息（如人脸、账号）。
- **OCR 文字识别**：内置离线 OCR 引擎，一键提取截图中的文字（支持中英文），无需联网，保护隐私。
- **贴图置顶**：支持将截图“钉”在屏幕最上层，方便对照参考或跨应用协作。
- **快捷键支持**：支持自定义全局快捷键，一键唤起截图。
- **隐私安全**：完全离线运行，不上传任何数据。
- **完全免费**：开源自由，打破收费壁垒。

## 📦 安装

### 方式一：GitHub Releases (推荐)

> 💻 **系统要求**：macOS 13.0 (Ventura) 及以上版本。

1. 前往 [Releases](https://github.com/songpl-AI/LibreShot/releases) 页面下载最新的 `.dmg` 安装包。
2. 双击打开 `.dmg` 文件，将 `LibreShot.app` 拖入 `Applications` 文件夹。

> ⚠️ **注意：首次打开如遇“无法验证开发者”**
> 
> 请按以下步骤操作（仅需一次）：
> 1. 双击打开 `LibreShot.dmg`。
> 2. 将 `LibreShot.app` 拖入 `Applications` 文件夹。
> 3. 单机 `LibreShot.app` 图标。在隐私与安全设置中，点击 **“仍要打开”**。
> 4. 忽略安全提示，本软件纯单机，不会联网。

如果仍然提示“文件已损坏”，请在终端运行以下命令修复：
```bash
xattr -cr /Applications/LibreShot.app
```

### 方式二：自行构建

如果您是开发者，可以自行编译源码：

```bash
# 1. 克隆代码
git clone https://github.com/songpl-AI/LibreShot.git

# 2. 打开项目
cd LibreShot
open LibreShot.xcodeproj

# 3. 使用 Xcode 编译并运行 (Cmd + R)
```
*要求：Xcode 14.0+，macOS 13.0+*

## 🚀 使用指南

### 1. 快捷键启动 (推荐)
- **区域截图**：默认快捷键 `Cmd + Shift + X`
- **全屏截图**：默认快捷键 `Cmd + Shift + A`

前往 **设置** 可随时自定义这些快捷键。这是最高效的使用方式。

### 2. 菜单栏启动
点击顶部菜单栏的“剪刀”图标，选择相应功能：
- **区域截图**
- **全屏截图**

*(注：菜单项旁边会自动显示当前绑定的全局快捷键，方便随时查看)*

### 3. 标注与编辑
截图完成后，会自动进入编辑模式，顶部工具栏提供以下功能：
- **形状工具**：点击矩形、圆形或箭头图标进行标注。
- **马赛克/模糊**：点击水滴图标，框选需要打码的区域。
- **文字工具**：点击 "T" 图标插入文本。
- **颜色/粗细**：选中标注对象后，可调整颜色和线条粗细。

### 4. 贴图 (Pin)
点击工具栏上的 **📌 (图钉)** 图标，当前截图将以悬浮窗口形式固定在屏幕最上层。您可以随意拖动它，双击即可关闭。这在对比代码、参考资料时非常有用。

### 5. OCR 文字识别
点击工具栏上的 **OCR** 图标，软件将自动识别截图中的文字，并弹窗显示识别结果，支持一键复制。

### 6. 设置
在菜单栏点击图标选择“设置...”，可以：
- **设置快捷键**：自定义“区域截图”和“全屏截图”的全局快捷键。
- **保存路径**：自定义截图文件的默认保存位置。
- **启动设置**：设置是否开机自启。
