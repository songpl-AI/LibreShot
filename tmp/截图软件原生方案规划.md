# mac 原生截图软件方案规划 (架构增强版)

> **版本说明**：本规划基于《AI 协作驱动开发指南》进行了增强，补充了架构设计、数据流向与自动化验证体系。

## 1. 技术框架与边界定义

### 1.1 核心技术栈
- **语言**：Swift 5+
- **UI 框架**：SwiftUI (主界面) + AppKit (系统级窗口控制/菜单)
- **截图核心**：ScreenCaptureKit (高性能，低延迟)
- **数据存储**：FileManager + UserDefaults

### 1.2 关键限制与权衡 (Trade-offs)
- **系统版本**：最低支持 **macOS 12.3+** (依赖 ScreenCaptureKit)。
  - *决策*：放弃旧版 macOS 支持以换取更高性能和更少代码量。
- **渲染性能**：
  - MVP 阶段：使用 SwiftUI `.drawingGroup()` 进行标注绘制。
  - 优化阶段：若出现卡顿，下沉至 CoreGraphics 或 Metal。
- **沙盒机制**：
  - 必须申请 `Screen Recording` 权限 (TCC)。
  - 文件保存需处理沙盒外写入权限 (使用 `NSSavePanel` 或 `Security Scoped Bookmarks`)。

## 2. 系统架构设计 (Architecture)

### 2.1 目录结构契约
```text
MyScreenShots/
├── App/
│   ├── MyApp.swift             # App 入口
│   └── AppDelegate.swift       # 处理菜单栏、Dock、生命周期
├── Core/                       # 纯业务逻辑 (无 UI，便于测试)
│   ├── Capture/                # 截图引擎 (ScreenCaptureKit 封装)
│   ├── Storage/                # 文件保存与命名策略
│   └── Hotkey/                 # 全局快捷键监听
├── Features/                   # 功能模块 (UI + ViewModel)
│   ├── Overlay/                # 全屏遮罩、选区交互
│   ├── Editor/                 # 标注画板、工具栏
│   └── Settings/               # 设置面板
├── Shared/                     # 通用工具 (Utils, Extensions)
└── Tests/                      # 自动化测试
```

### 2.2 核心数据流 (Data Flow)
1.  **触发 (Trigger)**：快捷键 / 菜单栏点击 -> `HotkeyService`
2.  **捕获 (Capture)**：`CaptureService` 调用 `SCStream` -> 获取 `CVPixelBuffer` / `CGImage`
3.  **编辑 (Edit)**：图片传入 `EditorViewModel` -> 用户在 Overlay 层绘制 -> 生成标注图层
4.  **合成 (Compose)**：原始图 + 标注图层 -> 合成最终 `NSImage`
5.  **输出 (Output)**：`ExportService` -> 写入磁盘 / 写入 `NSPasteboard`

### 2.3 状态机模型 (State Machine)
应用应由明确的状态驱动，避免 UI 逻辑混乱：
- **Idle**: 后台静默运行，监听快捷键。
- **Selecting**: 快捷键触发，显示全屏遮罩，等待用户框选。
- **Capturing**: 用户完成框选，正在捕获屏幕像素。
- **Editing**: 捕获完成，显示标注工具栏，等待用户编辑。
- **Processing**: 正在保存或复制。

## 3. 验证驱动体系 (Verification Strategy)

在编写业务代码前，优先确保核心逻辑可验证。

### 3.1 自动化测试分层
- **L1: 逻辑单元测试 (Logic Unit Tests)**
  - `NamingStrategyTests`: 验证文件名生成规则 (e.g., "Screen Shot 2024-02-07 at 10.00.00.png")。
  - `HotkeyValidator`: 验证快捷键注册是否冲突。
  - `StorageTests`: 验证文件写入权限和路径拼接。
- **L2: 资源泄漏测试 (Memory Tests)**
  - 使用 Instruments 验证连续截图 50 次后，`CVPixelBuffer` 是否被完全释放。

### 3.2 验收标准 (Acceptance Criteria)
- [ ] **权限**：首次启动正确弹出屏幕录制权限提示，拒绝后有引导。
- [ ] **多屏**：支持多显示器，能在鼠标所在屏幕正确触发。
- [ ] **高分屏**：Retina 屏幕截图分辨率正确 (2x/3x)，无模糊。
- [ ] **色彩**：P3 广色域屏幕截图色彩不丢失 (Color Profile 管理)。

## 4. 模块拆分与接口

| 模块 | 职责 | 关键类/协议 |
| :--- | :--- | :--- |
| **Capture** | 负责屏幕/窗口像素获取 | `ScreenCaptureKit`, `SCStreamOutput` |
| **Annotate** | 负责画笔、形状、文字绘制 | `CanvasView`, `ShapeModel` |
| **Hotkey** | 注册系统全局快捷键 | `CGEvent`, `Carbon` (或 `HotKey` 库) |
| **Storage** | 文件 I/O 与历史记录管理 | `FileManager`, `CoreData` (可选) |
| **Export** | 剪贴板交互与分享 | `NSPasteboard`, `NSSharingService` |

## 7. FAQ
Q：为什么复制/保存后没有弹窗提示？
A：为避免打断操作体验，成功只播放提示音；失败仍保留弹窗提示。

Q：成功提示音与 UI 提示的策略是什么？
A：成功场景仅提示音，不弹窗；失败场景保留弹窗与错误信息。
