安装与权限指南
01

下载，拖入应用程序

打开下载的 DMG，将 LibreShot 拖入“应用程序”。升级前先退出旧版。

02

允许屏幕录制

首次截图按提示授权。使用双击 Option 启动截图时，还需输入监控权限。

03

开始第一张截图

从菜单栏启动，或按 ⌘⇧X。框选、标注，然后把你的想法分享出去。

反馈问题与建议
支持哪些 Mac？

支持 macOS 13 及以上、Apple Silicon 与 Intel。翻译功能需要 macOS 26 及以上；复杂底纹、表格和特殊字体的原图翻译需要人工核对。

截图和识别文字会上传吗？

截图、OCR 与翻译文本在本机处理。首次下载翻译语言包与检查更新需要联网；语言包安装后可离线翻译。

截图完成后，会自动保存吗？

新用户默认仅复制到剪贴板。可在设置中开启自动保存，或用 ⌘S 手动保存、⌘⇧S 另存为。升级会保留原来的设置。

LibreShot 免费使用，源代码以 MIT 许可证开放。欢迎提交 Issue 或 Pull Request，也可以通过 GitHub Sponsors 支持项目维护。
