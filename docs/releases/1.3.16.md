# LibreShot 1.3.16

- 工具属性改为紧凑滑块与可编辑的精确数值，数字居中；移除折叠箭头，快捷颜色保留红、绿、蓝及自定义颜色。
- 调整常用默认值：线宽 3、矩形圆角 8、文字字号 24、序号字号 16；保留已保存的自定义设置。滑块实时预览，一次撤销恢复整次拖动。
- 切回“选择／移动”后，可拖选区内部空白处移动截图范围与标注；绘制工具保持选中，方便连续标注。
- 修复跟随工具栏导致选区拖动中断，以及移动后撤销编辑使标注跳回旧位置的问题。

悬浮隐藏、滚轮调节和阴影等更多样式暂缓。

## English

- Compact tool properties with sliders and editable, centered numeric values. Remove the collapse button and keep red, green, blue and a custom color picker.
- Set practical defaults: stroke width 3, rectangle corner radius 8, text size 24 and number size 16. Preserve saved settings; preview slider changes live and undo each drag as one action.
- Drag blank space in Select/Move mode to move the capture area and annotations. Drawing tools remain active for continuous annotation.
- Fix interrupted selection drags caused by the following toolbar and annotations jumping back when undoing an edit after moving the selection.

Hover hiding, wheel adjustment and additional styles such as shadows are deferred.
