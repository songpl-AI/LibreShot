# LibreShot 1.3.14

- 新增自动工具属性栏，选择工具或已有标注后显示对应选项。
- 各工具独立记忆颜色、粗细、字号和效果参数，支持恢复默认；已有标注的属性修改可撤销。
- 新增矩形圆角。
- 新增序号边框、填充、数字独立颜色；支持数字自动配色与实心序号无边框。
- 优化属性栏：共用色板，描边序号隐藏填充选项，屏幕边缘自动调整位置。

阴影、更多箭头风格、字体及样式预设暂缓。

- Automatic contextual tool properties with independent preferences, reset and undo.
