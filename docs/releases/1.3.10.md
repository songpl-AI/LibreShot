# LibreShot 1.3.10 · 连续文字输入与截图框交互修复

发布日期：2026-10-08。构建号 32，相对 1.3.9 build 31。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.10)。

## 本次更新

- **连续文字输入**：提交文字或点击外部取消空输入框后，仍保持文字工具。结束编辑的这次点击不会立即创建另一个输入框；下一次点击可以继续输入。显式切换工具仍按原规则取消未完成输入。
- **中文拼音输入**：尚未选字的拼音组合输入也实时更新文字框尺寸，避免长拼音被截住；同步界面时保留输入法的组合文字状态。
- **截图框移动**：选择模式下从外边框附近拖动可移动截图选区，内部空白拖动不再误移整个选区。八向控制点缩放和已有标注操作保留。
- **更新入口**：菜单栏的“检查更新”移到设置「关于」，继续打开 GitHub Releases 页面。
- **出厂工具顺序**：选择、画笔、矩形、椭圆、箭头、文字、序号、马赛克、模糊、属性、长截图、OCR、原图翻译、撤销、取消、完成、贴图、保存、另存为。仅新安装和恢复默认采用新顺序，升级保留已有自定义排序与隐藏项。

## 安装与升级

退出旧版，将 DMG 中的应用替换到 `/Applications/LibreShot.app`。保留偏好、文件访问书签和截图文件。包沿用 ad-hoc 签名，未经过 Apple 公证，支持 Apple Silicon 与 Intel；最低 macOS 13，翻译需要 macOS 26。

权限开关已开启却不能截图时，先退出 LibreShot，分别移除失效的录屏、输入监控条目，通过“+”精确添加当前安装路径，开启后重新启动。保存目录不可访问时，在应用设置中重新选择原目录。

## English summary

Text entry stays active after committing text or dismissing an empty field. The click that ends editing no longer creates another field immediately; the next click starts a new one. The editor resizes during Chinese pinyin composition while preserving uncommitted input. Move the capture region from its border; dragging empty space inside no longer moves it. Resize handles and annotation interactions remain available. Check for Updates moves to Settings → About and opens GitHub Releases. The revised default toolbar order applies to new installations and resets, preserving existing custom order and hidden items on upgrade.

Automated checks and real capture/save before and after restarting the same installed build passed, with full clipboard-image pixel comparisons. The maintainer confirmed physical double-Option triggering and Chinese pinyin input. The original tested build 32 DMG is published without rebuilding or re-signing. This universal ad-hoc package is not notarized; upgrades may require renewed permissions. Intel, older macOS, multiple displays and other physical input methods were not independently tested on this package. Memory investigation, the unified properties panel and new styles remain for later work.
