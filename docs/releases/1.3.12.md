# LibreShot 1.3.12 · 全屏标注与鼠标所在屏幕截图

发布日期：2026-10-10。构建号 35，相对 1.3.11 build 33。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.12)。

## 本次更新

- **全屏截图进入标注界面**：修复快捷键触发后只有音效、缺少可见结果的体验。捕获完成后显示整张截图，可继续标注；Enter、双击或完成按钮复制最终图片，并遵循自动保存设置。Esc 取消。
- **跟随鼠标选择屏幕**：在触发时读取鼠标所在显示器，捕获该屏幕的全屏内容，编辑窗口在目标屏幕打开。后续焦点或鼠标移动不会改变本次截图目标。鼠标位于显示器之间的空隙时回退到主屏。

## 安装与升级

退出旧版，将 DMG 中的应用替换到 `/Applications/LibreShot.app`，保留原设置和截图目录。本包为 Apple Silicon / Intel universal、ad-hoc 签名，未经过 Apple 公证；最低 macOS 13，翻译需要 macOS 26。

更新后如果已有权限开关开启但应用仍提示缺失，先退出 LibreShot，分别刷新屏幕录制和输入监控中 LibreShot 的既有条目，重新添加确切的安装路径后启动。保存目录不可访问时，在应用中重新选择原目录。

[安装授权规范](../operations/install-and-permissions.md)。

## English summary

Full-screen capture now opens the annotation editor instead of silently saving a file. Finish with Enter, double-click, or the completion button to copy the annotated result and save it when Auto Save is enabled. Esc cancels.

The capture uses the display under the pointer at trigger time and opens the editor on that display. Subsequent pointer or focus changes do not alter the selected display.

Actual capture, annotation, saving and clipboard inspection before and after restarting the same installed build, plus physical double-Option triggering, passed. Two physical full-screen captures selected the external display correctly; complete external-display export remains untested. Mac full-screen annotation and saving passed at 3024×1964. The Mac full-screen clipboard image was not obtained because the clipboard contained file types when inspected. Issue #26 is not claimed fixed. The original tested universal ad-hoc build 35 DMG is reused without rebuilding or re-signing.
