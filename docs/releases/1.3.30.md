# LibreShot 1.3.30

- 设置 > 基本设置新增“在程序坞中显示图标”：关闭时只有菜单栏；开启后可用 `⌘Tab` 切换、从程序坞右键退出，保存/另存为面板关闭后图标仍保持。
- 原图翻译控件并入属性条：目标语言、“原文/译文”、重译、校正集中到一条；再点工具栏“翻译”图标直接关闭翻译并保留原图。
- 语言选择增加“译为”标签和菜单箭头，不再像一段静态文字；完成状态改为“翻译完成，点选区可切换原文/译文”。

[下载](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.30) · [安装与授权](../operations/install-and-permissions.md)

## English

- Settings > General adds “Show icon in Dock”. Off keeps the app menu-bar only; on enables `⌘Tab` switching and quitting from the Dock context menu, and the icon stays after Save/Save As panels.
- In-place translation controls now live in the property bar: target language, original/translated views, retranslate and corrections in one row. Pressing the Translate toolbar icon again closes the translation and keeps the original image.
- The language picker gains a “Translate to” label and a menu chevron, so it no longer looks like static text; the completion message now reads “Translation complete; click the selection to switch views”.

Build 84. Same-package screenshots and saves passed before and after restart; the annotation stroke, input monitoring and clipboard contents were not separately captured. Ad-hoc signing; upgrades may require renewed permissions.
