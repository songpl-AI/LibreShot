# LibreShot 1.1.1（构建 6）

OCR 结果窗口点击“翻译”后，如缺少语言包，会显示 macOS 的下载确认和进度界面。语言包免费，由系统管理；首次下载需要联网，安装后可离线翻译。已安装的语言直接翻译。

取消下载后可以再次点击翻译；同语言重试会创建新的任务配置，避免一直等待。翻译期间禁用重复点击和切换目标语言，结束后恢复操作。

翻译会话按需创建，关闭 OCR 窗口时销毁承载视图并取消应用侧任务。没有新增常驻服务、轮询或应用侧语言模型缓存。已经确认开始的语言下载可能由 macOS 在后台继续，遵循系统弹窗说明。

系统下载提示、取消后连续重试和已安装语言的真实中译结果已验收，见 [验收记录](../qa/1.1.1.md)。长截图仍由用户自行验收，本版未修改长截图逻辑。
