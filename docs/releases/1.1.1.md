# LibreShot v1.1.1 · 自定义工具栏与翻译下载提示

发布日期：2026-09-13。构建号：6。本次公开发布包含此前本地试用的 1.1.0 改动，以下为相对 v1.0.4 的更新。

## 新功能与改进

- **自定义工具栏**：设置中勾选显示或隐藏工具，拖动工具行或使用上下箭头排序，一键恢复默认。完成和取消始终保留，但可以移动位置；配置从下一次截图生效。
- **工具名称提示**：鼠标停在按钮上可查看功能名称；统一按钮区域和布局，工具较多时自动换行。
- **四色样式入口**：颜色与字号按钮改为红、黄、蓝、绿四格色板，下方细色条显示当前颜色。
- **直接调整截图范围**：框选结束立即显示四角和四边控制点，使用标注工具时也能拖动缩放。
- **一次 Esc 取消**：包括正在输入文字或打开颜色面板时。
- **免费翻译语言包提示**：OCR 结果中点击翻译，缺少语言包时由 macOS 展示下载确认及进度。首次下载需要联网，安装后离线翻译；取消后可重试。

## 修复

- 修复设置窗口空白及不同设置入口行为不一致的问题。
- 改善录屏权限和采集错误提示，保留底层错误信息。
- 完成、保存、另存为、贴图和 OCR 包含尚未提交的文字。
- 自动保存失败时仍保留已复制的截图，并显示错误说明。
- 普通截图采集不合成鼠标指针；操作界面仍保留实时光标。
- 修复取消语言包下载后同语言重试一直等待的问题。

## 安装与升级

下载附件 `LibreShot-1.1.1-6.dmg`，退出旧版后，将新应用拖入 Applications 替换。工具栏配置和保存设置保留。`SHA256SUMS` 可用于校验下载文件。

- 应用要求 macOS 13+，安装包包含 Apple Silicon 与 Intel 架构；翻译功能要求 macOS 26+。
- 当前使用开发签名，尚未经过 Apple 公证。安装提示及录屏授权说明见 [README](../../README.md#-安装)。
- 语言包免费，由系统管理；已确认的下载可能在后台继续。也可在“系统设置 → 通用 → 语言与地区 → 翻译语言”管理。

## 验证与后续

工具栏、选区、保存、OCR 和翻译状态回归通过；实测系统下载弹窗、取消后连续重试及已安装语言的真实英译中通过。签名和 DMG 校验通过。测试环境为 Apple Silicon、macOS 26.5.2，其他系统版本和 Intel 实机仍需反馈。

“点击已有标注自动选中”留待后续，当前仍请使用“选择/移动”。隐藏工具主要用于简化操作，不代表卸载功能或明显减少内存。翻译按需启动，无新增常驻服务或轮询；尚未做完整进程内存的前后基准测量。

本版未修改长截图拼接逻辑；多帧拼接仍待人工验收。新日语语言包完整下载流程未执行，已验证提示和取消重试。
