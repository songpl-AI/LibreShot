# LibreShot 1.3.34

- 工具栏设置集中展示全部工具，可拖动排序，点选工具可设置显隐和快捷键。
- 双击贴图可设为关闭、复制并关闭或进入标注。
- 区域截图选区在启动时鼠标所在屏幕的边缘停住。

## English

- See all toolbar tools at once. Drag to reorder them, or select a tool to edit its visibility and shortcut.
- Choose whether double-clicking a pin closes it, copies and closes it, or opens annotation tools.
- Area selections stop at the edge of the display where capture started.
