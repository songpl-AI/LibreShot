# LibreShot 1.3.28

- 在截图上直接选字：单击整行、双击复制整行；拖选任意字符/词句，跨行拖选会带上起始行尾段、中间整行和结束行首段。
- `⌘A` 全选、`⌘C`/`Return` 复制；没有选中时直接复制全部。底部固定操作条显示“已选 N 字/行”或“已全选 N 行”。
- OCR 新增“图层/列表”切换；列表里的文字可编辑、可恢复原文，编辑只影响列表的复制/翻译，不回写图层。
- 指针模式下可直接按住矩形/椭圆拖动；矩形等绘图工具激活时，拖动手型边框也会移动原形状，不再新建。
- 贴图滚轮/捏合缩放时短暂显示当前比例。
- 放大镜读数统一为 sRGB；十字辅助线改为蓝色＋白色描边。
- 修复序号红/绿/蓝预设已选中但有时不显示打勾。

## English

- Select OCR text directly on the screenshot: click a line, double-click to copy it, or drag across characters and lines. Shift-free selection uses reading order and includes the trailing start line, full middle lines and leading end line.
- `⌘A` selects all, `⌘C`/Return copies; with nothing selected, copy all. The fixed footer shows characters/lines or “all selected”.
- OCR now has Layer/List switching. List text is editable and can be restored; edits affect only the list's copy/translation, not the image regions.
- In pointer mode, drag a rectangle/ellipse directly; with a drawing tool active, dragging the hand-cursor border moves the existing shape instead of creating a new one.
- Pinch/wheel zoom on a pinned image briefly shows the current percentage.
- The loupe reports sRGB; guide lines use a blue stroke with a white outline.
- Fixed number preset checkmarks sometimes missing for red/green.

Ad-hoc signing; upgrades may require renewed screen-recording/input-monitoring permissions.
