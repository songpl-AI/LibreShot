# LibreShot 1.3.24

- 文字确定后按屏幕分辨率绘制，不再发虚。
- 画笔落下后不再选中，也不能拖动，可以交叉着连续写。
- 色盘点一次打开、再点一次关闭；换工具、完成、取消或进入长截图时也会收起。
- 属性栏加高，色点、分段按钮和字号拉开间隔，不再互相重叠。
- 长截图的辅助边框和提示可以在远程桌面里显示。
