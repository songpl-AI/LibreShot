# LibreShot 1.3.8 · 标注操作与长截图回看优化

发布日期：2026-10-06。构建号 30，相对 1.3.7 build 29。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.8)。

## 本次更新

- **文字首次拖动**：按住已有文字或序号拖动即可选中并移动，减少误建输入框；文字编辑框内开始的选字拖动可以延伸到框外。保留双击编辑与撤销。
- **长截图短暂上滑**：有可信重叠且回看内容位于已捕获范围时，忽略反向帧，继续下滑沿用原拼接基准。保留真正缺帧及方向歧义的完整性检查。
- **序号样式**：新增实心/描边选择，默认实心；数字根据背景自动使用黑色或白色，颜色可在原面板选择，后续序号继承样式。
- **箭头与文字选框**：箭头使用随尺寸调整的实心尖端，文字编辑和选择边框更清晰。显示、命中范围和导出同步更新。

## 安装与升级

退出旧版，将 DMG 中的应用替换到 `/Applications/LibreShot.app`。保留偏好、文件访问书签和截图文件。包沿用 ad-hoc 签名，未经过 Apple 公证，支持 Apple Silicon 与 Intel；最低 macOS 13，翻译需要 macOS 26。

升级后权限可能仍绑定旧包。开关已开启却不能截图时，先退出 LibreShot，分别移除失效的录屏、输入监控条目，通过“+”精确添加当前安装路径，开启后重新启动。保存目录不可访问时，在应用设置中重新选择原目录。

## English summary

Existing text and numbers can be selected and moved on the first drag. Text selection started inside the editor can extend outside it. Long captures tolerate short reverse-scroll revisits with trusted overlap inside already captured content, retaining the forward stitching baseline and integrity checks. Number annotations offer filled and outlined styles with automatic contrasting digits; arrows use solid adaptive heads and text borders are clearer. Automated regression checks and native capture/save before and after restarting the same installed build passed. Physical Option gestures, three-finger dragging and Finder elastic bounce still require confirmation. Full bidirectional capture remains future work. The exact tested build 30 DMG is published without rebuilding or re-signing; this ad-hoc package is not notarized and upgrades may require renewed permissions.
