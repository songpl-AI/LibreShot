# LibreShot 1.3.23

- 精简工具属性栏，缩小控件与间距；选中工具自动显示属性，移除手动收起/展开。
- 优化滑块常用范围，小数值调整更细；保留精确输入、滚轮调整与原有较大参数。
- 菜单栏左键默认直接区域截图，支持自定义动作；右键显示完整菜单。
- 增加可关闭的十字辅助线，使用半透明细虚线与中心留空样式。
- 自定义颜色入口改为调色盘图标，修复普通鼠标点击无响应与面板被遮罩挡住的问题。

## English

- Compact tool properties with smaller controls and spacing; show properties automatically and remove manual collapse/expand.
- Refine slider ranges for finer adjustments to common values; retain exact input, wheel adjustments and existing larger values.
- Start area capture with a left click on the menu bar icon by default, with configurable actions; right-click opens the full menu.
- Add optional crosshair guides with fine translucent dashes and a clear center.
- Add a recognizable custom-color palette icon; fix mouse clicks failing to open the panel and the panel appearing behind the capture overlay.

Build 52 includes the 1.3.20–1.3.22 trial changes. Reuses the accepted DMG from source 76255fc; later commits update documentation only. Capture/save before and after restart, clipboard, real mouse color selection, OCR and physical double-Option passed on the maintainer’s Mac. Other macOS/display configurations remain unverified.
