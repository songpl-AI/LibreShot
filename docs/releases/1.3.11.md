# LibreShot 1.3.11 · 所有标注工具支持双击完成截图

发布日期：2026-10-10。构建号 33，相对 1.3.10 build 32。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.11)。

## 本次更新

- **双击完成截图（Issue #25）**：框选完成后，双击选区即可执行完成按钮的操作。适用于选择/移动、画笔、箭头、矩形、椭圆、文字、序号、马赛克和模糊工具，也适用于已有标注和文字输入状态；正在输入的文字会提交到成图。
- **遵循自动保存设置**：开启自动保存时，完成会复制并保存到原目录；关闭时仅复制。
- **避免意外标注**：序号工具下双击确认不会留下第一下点击意外放置的编号。普通单击、绘制与拖动继续立即响应。
- **可恢复原交互**：设置 → 快捷键中的“框选后双击完成截图”默认开启。关闭后恢复双击文字或序号编辑。工具栏和属性面板继续使用各自的交互。

## 安装与升级

退出旧版，将 DMG 中的应用替换到 `/Applications/LibreShot.app`。保留偏好、文件访问书签和截图文件。本包为 Apple Silicon / Intel universal，采用 ad-hoc 签名，未经过 Apple 公证；最低 macOS 13，翻译需要 macOS 26。

升级后可能需要刷新屏幕录制和输入监控授权。若开关已开启但应用仍报缺失，先退出 LibreShot，分别移除失效的对应条目，通过“+”添加当前确切安装路径，开启后重新启动。保存目录不可访问时，在应用设置中重新选择原目录。

## English summary

Double-click the selected capture area to finish with any annotation tool, including while entering text or over existing annotations. Text is committed before export. Finish copies the image and saves it when Auto Save is enabled; otherwise it only copies. Number-tool confirmation removes a number accidentally created by the first click. Ordinary clicks and drawing remain responsive. The option is enabled by default under Settings → Shortcuts; disable it to restore double-click text and number editing.

Automated checks and actual capture, annotation, double-click completion, saving and clipboard inspection before and after restarting the same installed build passed. The maintainer confirmed physical double-Option triggering and full-screen capture. The original tested build 33 DMG is published without rebuilding or re-signing. This universal ad-hoc package is not notarized; upgrades may require renewed permissions.

Issue #26 concerns an overlay disappearing inside another application's native full-screen Space on macOS 27.2 Beta. It was not reproduced on the local macOS 26.5.2 system and is not claimed fixed. The reported Beta environment, Intel and older macOS were not tested on the final package. Memory work and the unified properties panel remain for later updates.
