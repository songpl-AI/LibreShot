# LibreShot 1.3.4 · 画笔选框与默认工具

发布日期：2026-10-05。构建号 23，相对 1.3.3 build 21。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.4)。

- 普通截图框选完成、长截图进入标注编辑后，默认选中“选择/移动”；绘图工具由用户主动选择，不再自动指定矩形。
- 修复闭合或不规则画笔笔迹的浅蓝选框只覆盖起终点的问题，现在包含整条笔迹，并可从选框内部整体拖动。
- 标注移动和画笔/模糊绘制加入拖动容差，减少轻点、手部抖动引起的误移动或误画；保留闭合笔迹、撤销和移动回原位行为。
- 新增逐包安装与授权验收规范，打包时附带规范；维护操作固定安装路径、清理旧应用副本，分别检查录屏、输入监控与保存目录授权。

## 安装与升级

仍采用 ad-hoc 签名，未经过 Apple 公证；无需付费开发者账号。先验证 SHA256SUMS，退出 LibreShot，用 DMG 中的应用替换 `/Applications/LibreShot.app`，只运行当前副本，保留用户设置和截图文件。

升级后即使授权开关为开启，也可能绑定旧包。先退出应用，在系统设置 → 隐私与安全性中分别检查“录屏与系统录音”（旧版为“屏幕录制”）及已启用 Option 手势所需的“输入监控”；失效项移除后通过“+”添加准确的 `/Applications/LibreShot.app`，开启后重启。完成实际截图保存，再退出并重新打开复验。自动保存目录缺少访问授权时，通过应用提示重新选择原目录。

完整步骤见 [安装与授权验收规范](../operations/install-and-permissions.md)。规范不能保证 ad-hoc 更新免重新授权；不以关闭系统安全保护作为安装办法。首次打开系统安全提示处理见 [安装说明](../../README.md#-安装)。

## English summary

Capture editing now starts in Select/Move, including the long-image editor. Drawing tools are chosen explicitly. Freehand selection bounds cover the entire stroke, including closed and irregular paths, and the selected interior can move the stroke. Drag tolerance reduces accidental movement and tiny marks while preserving undo and closed paths. The verified build 23 package passed native capture/save checks before and after restart on Apple Silicon/macOS 26. This ad-hoc signed package is not notarized; updates may require renewing Screen Recording and Input Monitoring permissions. An installation and permission acceptance procedure is included.
