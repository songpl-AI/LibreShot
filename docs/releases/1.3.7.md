# LibreShot 1.3.7 · 文字原位编辑与序号圆形编辑

发布日期：2026-10-06。构建号 29，相对 1.3.6 build 28。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.7)。

## 本次更新

- **文字原位编辑**：修复双击文字进入编辑时的位置与样式跳变。显示、原生输入和导出共享字体字重、中文回退字体、尺寸与字形原点；支持中英文、多行和不同字号。
- **序号圆形编辑**：编辑时保留圆圈、颜色和线宽，数字始终以原中心定位；多位数字自动扩大圆圈，不再切换为矩形输入框。全选数字、回车确认、Esc 取消、改号校验和撤销保持可用。
- **初始尺寸与样式**：编辑已有文字立即恢复原字号、颜色和实际尺寸，光标放到末尾；新建文字清除旧编辑框尺寸。

## 安装与升级

退出旧版，将 DMG 中的应用替换到 `/Applications/LibreShot.app`。保留偏好、文件访问书签和截图文件。本包沿用 ad-hoc 签名，未经过 Apple 公证，支持 Apple Silicon 与 Intel；最低系统 macOS 13，翻译需要 macOS 26。

升级后录屏与输入监控可能仍绑定旧包。开关开启却不能截图时，先退出 LibreShot，分别移除失效条目，通过“+”添加当前安装路径，开启后重新启动。输入监控用于已启用的双击 Option。保存目录无法访问时，通过应用设置重新选择原目录。

## English summary

Text annotations retain their position, font weight, size and color when entering inline editing. Display, native input and export share TextKit layout, including Chinese font fallback. Number editing keeps the original circle, color, line width and center; multi-digit values expand the circle while remaining centered. Commit, cancel, validation and undo remain supported. Automated glyph and regression checks passed, as did native capture/save before and after restarting the same installed build. The maintainer tested it and approved publication. The exact tested build 29 DMG is released without rebuilding or re-signing. This ad-hoc package is not notarized and upgrades may require renewed permissions.
