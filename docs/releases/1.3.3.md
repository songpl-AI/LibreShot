发布日期：2026-10-05。构建号 21，相对 1.3.2 build 20。

[下载安装包与 SHA256SUMS](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.3)。

## 安装与权限

继续使用 ad-hoc 签名，未经过 Apple 公证，无需付费开发者账号。退出旧版，将 DMG 内的 LibreShot.app 放入“应用程序”，只运行一份。下载后按 SHA256SUMS 校验。

升级后可能需要重新授予录屏和输入监控：旧开关开启但无效时，退出应用，在系统设置中移除 LibreShot 对应旧项目，再添加确切的 `/Applications/LibreShot.app`，开启后重新打开。输入监控仅用于已开启的双击 Option；自动保存无目录授权时按应用提示选择目录。首次打开的安全提示处理见 [1.3.2 安装说明](1.3.2.md#安装与升级权限)。

## #9 建议的取舍

核心交互和截图圆角已有实现，本版补齐马赛克遗漏。矩形标注小圆角和绘制过程中显示控制点暂缓；像素放大镜与固定加粗 2px 暂不做。保留可隐藏的选择工具。关闭综合 Issue 不表示十二条全部照原样实现；逐项状态见 [审核记录](../qa/issue-audit-20261005.md)。约 10 MB 内存目标仍保持取消。
