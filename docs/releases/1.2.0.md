# LibreShot 1.2.0 · 标注选择与形状缩放

发布日期：2026-09-13。构建号：7。本次更新相对 v1.1.1。

## 怎么使用

1. 框选截图范围后，照常画矩形、椭圆、箭头或其他标注。
2. 点一下已有标注，自动切换到选择模式。矩形和椭圆请点边框；文字点文字区域。
3. 选中矩形或椭圆后，拖动边框或内部空白可移动；拖动八个蓝色控制点可放大、缩小或改变宽高，最小边长为 12 点。
4. 外层白色控制点仍用于调整截图范围。如果蓝白控制点重叠，优先调整截图范围。

为兼容连续绘制，画完图形不会自动切换工具。需要修改时，先单击选中，再拖动。启用绘图工具时，从旧标注上直接按住拖动仍绘制新标注；文字和序号工具的拖动不会新增标注。选中图形内存在其他标注时，点击其可见内容优先选择该标注。

文字保留双击编辑及右下角字号缩放；本次新增八向缩放仅适用于矩形、椭圆。空心图形和线条按实际笔画命中，重叠时优先命中上层标注。按一次 Esc 仍取消截图。

## 运行开销与边界

命中检测在手势开始时进行，没有新增后台服务、定时器或鼠标悬停扫描。拖动时更新当前选中标注，额外绘制最多八个控制点。预期日常截图开销很小，但尚未做前后进程内存或大量标注的性能基准测量。

## 安装与升级

下载 Release 附件 `LibreShot-1.2.0-7.dmg`，退出旧版，将应用拖入 Applications 替换。工具栏顺序、隐藏项、保存目录和自动保存设置保留。附件 `SHA256SUMS` 可用于校验安装包。

- 要求 macOS 13+，包含 Apple Silicon / Intel 通用构建；OCR 翻译要求 macOS 26+。
- 使用开发签名，尚未经过 Apple 公证。安装及录屏授权说明见 [README](../../README.md#-安装)。
- 本次正式发布沿用已经本机验收的 1.2.0（构建 7）安装包，未更改程序代码。

## 验证

64 组自动选择组合、矩形/椭圆 16 组缩放控制点，以及原有选区、工具栏、文字和保存回归通过。原生界面实测矩形移动、放大、缩小、继续画箭头及文字双击编辑通过；本机试用反馈无问题。签名、通用架构、DMG 和 SHA256 校验通过。环境为 Apple Silicon、macOS 26.5.2；其他系统及 Intel 实机仍需反馈。

感谢 Issue [#2](https://github.com/songpl-AI/LibreShot/issues/2) 的自动选择建议，本次完成 [#3](https://github.com/songpl-AI/LibreShot/issues/3) 跟踪的交互需求。

## English highlights

- Click an existing annotation to select it without first switching to Select/Move. Rectangles and ellipses are selected by their outlines.
- Move selected rectangles and ellipses from their interiors or outlines; resize them with eight blue handles. White handles still resize the capture region.
- Direct drags keep drawing with the active tool. Text editing and one-press Esc cancellation remain available.
- Upgrade by replacing the old app with `LibreShot-1.2.0-7.dmg`; preferences are preserved. Universal macOS 13+ package, development-signed and not notarized. See the [English installation guide](../../README_EN.md#-installation).
