# LibreShot 1.2.0 · 标注选择与形状缩放

状态：本地试用，尚未发布到 GitHub。构建号：7。日期：2026-09-13。

## 怎么使用

1. 框选截图范围后，照常画矩形、椭圆、箭头或其他标注。
2. 点一下已有标注，自动切换到选择模式。矩形和椭圆请点边框；文字点文字区域。
3. 选中矩形或椭圆后，拖动边框或内部空白可移动；拖动八个蓝色控制点可放大、缩小或改变宽高，最小边长为 12 点。
4. 外层白色控制点仍用于调整截图范围。如果蓝白控制点重叠，优先调整截图范围。

为兼容连续绘制，画完图形不会自动切换工具。需要修改时，先单击选中，再拖动。启用绘图工具时，从旧标注上直接按住拖动仍绘制新标注；文字和序号工具的拖动不会新增标注。选中图形内存在其他标注时，点击其可见内容优先选择该标注。

文字保留双击编辑及右下角字号缩放；本次新增八向缩放仅适用于矩形、椭圆。空心图形和线条按实际笔画命中，重叠时优先命中上层标注。按一次 Esc 仍取消截图。

## 运行开销与边界

命中检测在手势开始时进行，没有新增后台服务、定时器或鼠标悬停扫描。拖动时更新当前选中标注，额外绘制最多八个控制点。预期日常截图开销很小，但尚未做前后进程内存或大量标注的性能基准测量。

签名包为 Apple Silicon / Intel 通用构建，使用本机开发签名，未进行公证。本次不更改工具栏、保存目录或录屏权限设置。GitHub 最新公开版仍为 1.1.1；Issue #3 待公开发布后再回复关闭。
