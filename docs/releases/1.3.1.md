# LibreShot 1.3.1 · 权限提示与截图体验修复

发布日期：2026-09-28。构建号：18。相对 v1.3.0 更新。

## 修复

- 录屏权限被拒绝或旧授权失效时，每次运行最多发起一次系统授权请求、显示一次应用内恢复指引；重新获得屏幕读取能力后可恢复正常状态。
- 预览截图失败时不再显示灰色截图遮罩，避免将 macOS 授权弹窗挡在遮罩下方；重复触发截图时过期预览也不会重新显示遮罩。
- 首次调用系统录屏授权时不再同时显示应用自己的权限错误弹窗，避免两个弹窗重叠。
- 截图工具栏改用清晰的不透明背景，避免按钮看起来整体处于禁用状态。
- 圆角截图半径从 8 点增至 16 点；PNG 透明圆角在复制、保存和标注导出路径保留。
- 原图位置翻译成功后自动收起操作控件；点击图像空白处可在原图与译文之间切换，拖动和标注仍按原有交互执行。

## 安装与权限

此版本延续 GitHub ad-hoc 签名分发，未经过 Apple 公证。请从本项目 Release 下载 DMG，核对 `SHA256SUMS`，退出旧版并替换“应用程序”中的 LibreShot。macOS 可能阻止首次打开；可按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中允许。

**从旧版升级后可能需要重新授权。** 退出 LibreShot，在“隐私与安全性 → 屏幕录制/录屏与系统录音”中移除旧的 LibreShot 权限项，添加“应用程序”里当前的 LibreShot，并开启权限；如启用了双击 Option，再检查“输入监控”。按系统提示退出并重新打开应用。不要同时运行旧版和新版，也不要全局关闭 Gatekeeper。

## 验证与边界

自动回归覆盖权限提示门控、权限失败时的遮罩清理、圆角像素、工具栏和原图翻译切换。本地安装版已验证旧 ad-hoc 授权与新签名不匹配时的恢复流程、实体快捷键截图、双击 Option、工具栏、圆角及原图翻译切换；首次系统授权弹窗与其他交互的完整实机验收状态见 [本地构建验收](https://github.com/songpl-AI/LibreShot/blob/v1.3.1/docs/qa/1.3.1-18-local.md)。独立内存样例未证明持续线性泄漏；完整应用在报告者的约 350 MiB 场景仍待复现，因此本版没有宣称达到 Issue #5 的约 10 MB 空闲目标。

本版针对 [Issue #7](https://github.com/songpl-AI/LibreShot/issues/7)。

## English summary

- Limit repeated Screen Recording permission prompts and show recovery guidance once per run.
- Improve capture toolbar contrast, make rounded corners clearer, and let users click the translated image to switch between original and translation.
- The GitHub DMG remains ad-hoc signed and is not notarized. Updates may require granting Screen Recording and Input Monitoring again.
