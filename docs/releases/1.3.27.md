# LibreShot 1.3.27

- 新安装和「恢复默认」使用这套工具顺序：选择/移动、画笔、矩形、椭圆、箭头、文字、序号、马赛克、模糊、识别文字、原图翻译、撤销、贴图到屏幕、保存、另存为、长截图、取消截图、完成。已经保存过自己顺序的用户不受影响。
- 设置里的工具栏从左到右排列，和截图工具栏一致，超出页面的部分可以左右滑动。
- 开始截图时不再整屏抖动。

## English

- New installs and Restore Defaults use the current toolbar order. Saved custom orders stay as they are.
- Toolbar settings run left to right, matching the capture toolbar, and scroll sideways.
- Starting a capture no longer shifts the whole screen.

The accepted package reports 1.3.24 (build 68) and was not rebuilt. Ad-hoc signing; upgrades may require renewed permissions.
