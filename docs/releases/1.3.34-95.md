# LibreShot 1.3.34（Build 95）

- 区域、全屏和长截图的全局快捷键支持单独使用 F1–F19。
- 长截图拼接中断时保留已捕获内容，可滚回上次接上的位置后重试。降低大长图成图时的内存峰值。
- 多屏下，开始框选前区域截图随指针换屏。选区保留在当前显示器内。

## English

- Use F1–F19 without modifiers for global area, full-screen, and long-capture shortcuts.
- If long capture stops stitching, scroll back to the last matched position and retry without losing captured content. Reduce peak memory when rendering large long captures.
- On multiple displays, area capture follows the pointer until you begin selecting. The selection stays within the active display.
