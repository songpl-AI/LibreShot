# LibreShot 1.3.5 · 默认工具配置与序号编辑

发布日期：2026-10-05。构建号 24，相对 1.3.4 build 23。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.5)。

## 本次更新

- **自选默认工具**：在设置的工具栏页选择截图后的默认工具，保存后普通截图与长图编辑均使用该选择。出厂默认仍是“选择/移动”；默认工具被隐藏或配置无效时回退选择模式。
- **序号修改与重新编号**：双击序号输入 1–9999，回车提交，Esc 取消改号。改为 N 后下一序号从 N+1 开始；改成 1 可开始另一组编号。输入数字不会触发工具快捷键。删除最近创建或明确改号的序号会恢复下一编号，删除中间项不重排其他序号；支持撤销。
- **序号缩放与样式继承**：选中序号后拖动右下角手柄，数字和圆形背景同步缩放，中心保持不变；下一个序号继承最近的大小和颜色。多位数字的背景、选框与导出使用一致的几何范围。
- **安装规范补充**：升级前记录并保留用户设置，系统授权选择面板核对当前应用完整路径，避免缓存的旧副本身份干扰授权。

## 安装与升级

沿用 ad-hoc 签名，未经过 Apple 公证，无需付费开发者账号。校验下载包后退出 LibreShot，将 DMG 中的应用安装到 `/Applications/LibreShot.app`，只运行这一份当前副本；保留用户设置、保存目录及截图文件。

更新后系统权限可能仍关联旧包。如果已开启却报权限不足，先退出应用，在系统设置 → 隐私与安全性中移除失效的 LibreShot 条目，通过“+”添加准确的 `/Applications/LibreShot.app` 并重新开启，再退出并重新打开。屏幕录制与输入监控分别检查，后者仅用于已启用的双击 Option 手势。保存目录无访问授权时，在应用内重新选择原目录。完成实际截图保存，并同包重启后复验。

## English summary

Configure the default capture tool in toolbar settings; Select/Move remains the factory default. Double-click numbered annotations to edit values from 1 to 9999; setting N makes the next number N+1. Resize a number using its bottom-right handle, and subsequent numbers inherit its size and color. Editing, deletion and resizing support undo. The verified build 24 package passed native capture/save checks before and after restart on Apple Silicon/macOS 26, and the user reported no issues during trial. This ad-hoc signed package is not notarized; updates may require renewing Screen Recording and Input Monitoring permissions. The installation procedure and SHA256SUMS are included.
