# LibreShot 1.3.0 · 原图翻译与截图工作流

发布日期：2026-09-27。构建号：15。相对 v1.2.0 更新。

## 主要变化

- 新增“在原图位置翻译”：识别截图文字并将译文放回对应位置，可校正单个区域、切换原图、复制、保存或继续标注。相邻段落行使用一致字号；译文过长时会提示修改或排除该区域，不会静默截断。
- 长截图默认进入可滚动、缩放的标注窗口；也可在设置中选择预览后复制或保存。改进连续滚动、重复列表、小幅位移和固定底栏的拼接与失败提示。
- 工具栏按自定义顺序直接显示已启用工具，窄窗口自动换行，不再藏进“更多”菜单。增加可配置的编辑工具快捷键、空格动作，以及可选的双击 Option 区域截图。
- 修复圆角截图导出、OCR 翻译按钮与复制译文、保存快捷键等问题。改进截图、OCR、长图和翻译窗口的内存生命周期；系统设置要求退出并重新打开时不再被应用拦截。

## 安装与权限

下载 `LibreShot-1.3.0-15.dmg`，退出旧版后将应用拖入“应用程序”替换；偏好设置和截图文件不会被安装包清理。附件 `SHA256SUMS` 可用于校验下载。应用为 Apple Silicon / Intel 通用构建，基本截图需要 macOS 13+；系统翻译和原图翻译需要 macOS 26+ 及相应语言包，首次下载语言包需要联网。

**重要：此构建仅为 ad-hoc 签名，未获得 Developer ID 签名或 Apple 公证。** macOS Gatekeeper 默认可能拒绝直接打开。请确认下载来源和 SHA-256，再依照 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”中决定是否允许；不要全局关闭 Gatekeeper。此安装体验不同于已公证的软件，受管理的 Mac 也可能不允许例外。

首次截图需授予“屏幕录制/录屏与系统录音”；双击 Option 需另授予“输入监控”。由于本包使用临时签名，从旧版升级时 macOS 可能要求重新授权并退出、重新打开应用。具体步骤见 [中文 README](https://github.com/songpl-AI/LibreShot/blob/v1.3.0/README.md#-安装) 或 [English README](https://github.com/songpl-AI/LibreShot/blob/v1.3.0/README_EN.md#-installation)。

## 已知边界与验证

- 原图翻译优先适用于纯色背景的网页、文档和软件界面；复杂底纹、表格与特殊字体不保证无痕还原，导出前请检查。未修改的文字保留原图像素。
- 内存优化不代表 OCR、翻译和长截图后会回到约 10 MB。Issue [#5](https://github.com/songpl-AI/LibreShot/issues/5) 仍开放，真实试用记录见 [14 版内存 QA](https://github.com/songpl-AI/LibreShot/blob/v1.3.0/docs/qa/1.3.0-14-local.md)。
- 自动回归覆盖截图尺寸与圆角、长图拼接、工具栏顺序/换行、原图翻译溢出与字号、OCR/翻译生命周期和双击 Option 判定。15 版已在 Apple Silicon、macOS 26.5.2 本机安装，录屏与输入监控授权及系统重启通过，原图翻译的实机显示获试用者认可。Finder 列表长截图的更多真实场景、macOS 13/14 和 Intel 实机仍欢迎反馈。[15 版 QA](https://github.com/songpl-AI/LibreShot/blob/v1.3.0/docs/qa/1.3.0-15-local.md)

本版处理 Issue [#4](https://github.com/songpl-AI/LibreShot/issues/4) 的截图与快捷键问题，以及 [#6](https://github.com/songpl-AI/LibreShot/issues/6) 的原图翻译与工具栏建议；极致后台内存目标继续跟踪于 #5。

## English highlights

- Translate recognized text at its original image position, edit regions, compare with the original, and export or annotate the result. Adjacent paragraph lines use a consistent type size. Requires macOS 26+.
- Long captures open in a scrollable, zoomable annotation editor by default. Capture stitching, toolbar wrapping and custom order, editor shortcuts, Space actions, and optional double-Option capture are improved.
- Universal macOS 13+ build. **Ad-hoc signed and not notarized:** Gatekeeper may block it until you explicitly allow this app under Apple's official instructions. Screen Recording is required for capture; Input Monitoring is also required for double-Option.
- Issue #5's approximately 10 MB idle-memory goal remains open. Complex-background in-image translation and other macOS/Intel configurations need further feedback.
