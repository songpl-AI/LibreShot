# LibreShot 1.3.2 · 长截图与 OCR 资源释放修复

状态：待发布候选；构建号 20。相对 GitHub v1.3.1 (18)。

## 更新

- 修复重复列表中细微的文字变化被近似去重丢弃，导致长截图中间帧断开。短暂未匹配后可以恢复继续拼接；结束时仍未接上会提示失败，避免输出残缺图。
- OCR 改为包内按需退出的沙盒辅助进程，完善取消、超时和异常处理。
- 自动保存目录没有写入权限时，可选择目录并保留授权，重试当前截图；取消仍保留已复制图片。
- 改善单击和轻微抖动创建无效形状、标注选择/删除/撤销与控制点交互，统一工具快捷键设置；编辑器关闭后主动释放图片。
- 优化重复复制图片的 PNG/TIFF 编码缓冲持有，保留透明度、Retina 尺寸及应用退出后的粘贴。

## 安装与升级权限

继续使用 GitHub **ad-hoc 签名**分发，无需付费开发者账号，未经过 Apple 公证。下载 DMG 和同版本 `SHA256SUMS`，校验后打开 DMG，将 `LibreShot.app` 拖入“应用程序”。升级前退出旧版，只运行一份 LibreShot。

首次打开可能需要按 [Apple 官方指引](https://support.apple.com/zh-cn/102445) 在“系统设置 → 隐私与安全性”确认打开。请只从本项目 Release 下载，不全局关闭系统安全检查。

截图需要“屏幕录制 / 录屏与系统录音”权限。双击 Option 默认关闭，启用时另需“输入监控”。更换 ad-hoc 版本后，旧开关即使显示开启，也可能仍对应旧签名：退出应用，移除对应的旧 LibreShot 权限项，再精确添加 `/Applications/LibreShot.app`，开启并按提示退出、重新打开。只更新 LibreShot 的项目，不修改其他应用的权限。自动保存无目录授权时按提示选择保存目录。

## 已验证与边界

- 长截图真实 Finder 像素 133 帧重放逐像素正确，完整回归通过；用户实测约 100 / 120 帧短暂警告后恢复累计，最终图片正常。
- 当前 Preview 输入监控开启并重启后缺失提示消失，用户实体 Option 按键可以触发截图遮罩。
- 此前完整 Preview 已通过 45 次原生 OCR/关窗、原图翻译和 PNG/TIFF 像素一致性验收。OCR 第 5 至 45 次闲置主进程约 75.6 → 77.2 MiB；冷基线增量仍约 41.4 MiB，不宣称达到约 10 MiB 目标。
- Apple Silicon / macOS 26 的当前样例已验证；Intel、macOS 13/14、多显示器、其他滚动内容及完整 Option 边界仍待补验。翻译功能需要 macOS 26+；复杂背景与原字体精确还原仍有限制。
- 发行 DMG 已完成双架构、嵌套签名、沙盒权限、挂载及校验值检查，见 [发行包核验](../qa/1.3.2-20-package-20261005.md)。
- 本机安装到 `/Applications` 后，已验证旧签名录屏/输入监控记录更新、真实截图保存、374 字符 OCR 及同签名重启授权复用。实体 Option 的完整边界、GitHub 下载后的首次 Gatekeeper 流程和其他设备仍待验；本页不表示已经公开发布。

## English summary

- Preserve small real changes in repeated scrolling lists to avoid dropping overlapping frames.
- Run OCR in a bundled, sandboxed helper that exits after recognition; improve cancellation and error handling.
- Improve save-directory permission recovery, annotation interactions, and repeated image-copy memory behavior.
- GitHub distribution remains ad-hoc signed and is not notarized. Updates may require renewing Screen Recording and Input Monitoring permissions. The overall 10 MiB memory target remains unmet.
