# LibreShot 1.1.0（构建 5）

本版集中改善截图工具栏和编辑操作，作为本机签名试用版交付。

- 设置中可显示、隐藏和排序工具，支持拖动、上下移动及恢复默认。完成和取消始终保留，设置在下一次截图生效。
- 工具栏悬停显示名称，颜色与字号入口改为红、黄、蓝、绿四格色板，下方细色条表示当前颜色。
- 框选结束立即显示八个缩放控制点，使用标注工具时也可以直接拖动控制点。
- 按一次 Esc 取消截图，包括文字输入和颜色面板打开时。
- 屏幕采集不合成鼠标指针；实时操作光标仍保留。
- 修复设置窗口入口、截图错误说明，以及自动保存失败时仍保留已复制截图。
- 完成、保存、另存为、贴图和 OCR 均提交尚在输入的文字。

当前仍需人工验收真实滚动拼接，以及安装语言模型后的跨语言翻译。点击已有标注自动切换选中功能留待后续版本；本版仍需先进入“选择/移动”。详细证据及测试边界见 [验收记录](../qa/1.1.0.md)。

安装包使用本机配置的开发签名，未公证，也未发布到 GitHub。
