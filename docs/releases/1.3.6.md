# LibreShot 1.3.6 · 马赛克与模糊效果、实时补涂

发布日期：2026-10-06。构建号 28，相对 1.3.5 build 24。

[下载 DMG、SHA256SUMS 与安装授权规范](https://github.com/songpl-AI/LibreShot/releases/tag/v1.3.6)。

## 本次更新

- **效果算法**：马赛克按原图像素块平均取色，网格保持稳定；模糊显示真实高斯效果。预览和导出共用渲染器，重复涂抹同强度时不反复叠加模糊。
- **两种应用方式**：马赛克和模糊均支持“涂抹 / 框选”，在效果参数面板切换；拖动过程中持续更新预览，修复必须松手后才显示的问题。
- **连续补涂**：涂抹松手后不自动选中、不出现选框，可以直接继续画下一笔或覆盖补涂。编辑旧笔迹时主动切换“选择/移动”；框选保留选中和移动、缩放行为。
- **参数调节**：两种涂抹默认笔刷大小均为 20，可选 20/36/60/90/120；马赛克颗粒可选 8/12/16/24/32，默认 16；模糊强度可选 4/8/12/20/32，默认 12。参数修改支持撤销。
- **工具图标**：马赛克改为九宫像素块，模糊改为柔边圆形，并补充操作提示。
- **换包流程**：新增固定打包与安装脚本，核验镜像和应用，旧应用移至废纸篓，失败自动恢复；保留偏好及保存目录。授权仍通过系统设置逐项处理。

## 安装与升级

退出旧版，把 DMG 中的 LibreShot.app 安装到 `/Applications/LibreShot.app`，保留原设置和截图文件。本包沿用 ad-hoc 签名，未经过 Apple 公证。先核对 SHA256SUMS，再按 [首次打开说明](../../README.md#-安装) 操作。

升级后录屏与输入监控可能仍绑定旧签名。如果开关已开启却报权限不足，先退出应用，分别移除失效条目，用“+”添加当前安装路径并开启，重新打开。输入监控仅用于启用的双击 Option。保存目录报访问错误时在应用内重新选择原目录。

## English summary

Both Mosaic and Blur support Brush and Rectangle modes with continuously refreshed previews. Brush strokes stay unselected after release, allowing immediate overlapping strokes; use Select/Move to edit them. The default brush width is 20. Mosaic uses block averages on a stable grid; blur uses Gaussian filtering with separate width and strength controls. Preview and export share the renderer. Icons and the local upgrade workflow are improved. The user tested build 28 and approved publication; detailed native capture/save and restart checks were not independently repeated on this final build. The exact installed DMG is published without rebuilding or re-signing. This ad-hoc package is not notarized and updates may require permission renewal.
