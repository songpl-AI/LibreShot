# 原位文字提取 · 静态原型

2026-10-20。对应 [Issue #46](https://github.com/songpl-AI/LibreShot/issues/46)。本文件只用于确认交互，尚未改代码。

![原型](ocr-in-place-20261020.png)

## 这张图表达的流程

1. **识别后原图保留**：不再像现在这样把截图替换成独立文字窗口；识别到的每一行文字在原图上有一条很淡的虚线下划线，表示可点。
2. **点选一行**：点文字后出现蓝色选区；选区下方浮出操作条“已选 3 段 / 复制 / 全选 / ×”。
3. **多选**：拖拽框选或 `⌘A` 全选，`⌘C` 复制；`Esc` 退出文字层。
4. **列表模式保留**：现有 OCR 文字窗口仍作为“列表模式”入口，不删除。

## 待确认的交互决策

- 点击一行：先选中再点“复制”，还是单击就直接复制？
- 多选：是否保留拖拽框选和 `⌘A`，还是只做单击单行？
- 操作条：跟随选区浮动，还是固定在窗口底部？
- 文字层只读复制，还是允许双击改字后再复制？
- 列表模式入口放哪里：顶部按钮、右键菜单，还是保留快捷键？

## 暂不包含

- 不承诺文字位置与排版完全还原（多栏、旋转文字会按识别框近似）。
- 不替代现有 OCR 列表窗口；先做叠加层，稳定后再考虑统一。
- 不改属性栏、翻译和标注逻辑。
