# 原位文字提取 · 静态原型

2026-10-20。对应 [Issue #46](https://github.com/songpl-AI/LibreShot/issues/46)。本文件只用于确认交互，尚未改代码。

![原型](ocr-in-place-20261020.png)

## 已确认的交互

1. **识别后原图保留**：不再把截图替换成独立文字窗口；识别到的每一行文字在原图上有一条很淡的虚线下划线，表示可点。
2. **单击选中**：点一行显示蓝色选区；底部固定操作条显示“已选 3 行 / 复制 / 全选 / 完成”。
3. **双击复制单行**：作为快捷方式，不替代单击选中。
4. **多选**：拖拽框选或 `⌘A` 全选，`⌘C` 复制；`Esc` 退出文字层。
5. **只读**：v1 不允许直接改字；需要编辑或查看全文时切到“列表”。
6. **列表模式保留**：顶部“图层 / 列表”切换，现有 OCR 文字窗口不删除。

## 这版相对上一版的变化

- 操作条从“跟随选区浮动”改为**固定在截图下方**，不再遮挡识别文字。
- 明确“单击选中、双击单行复制”，单击不会直接覆盖剪贴板。
- 顶部增加“图层 / 列表”切换，列表模式保持可见入口。
- 底部固定条同时显示选中数量和快捷提示。

## 暂不包含

- 不承诺文字位置与排版完全还原（多栏、旋转文字会按识别框近似）。
- 不替代现有 OCR 列表窗口；先做叠加层，稳定后再考虑统一。
- 不改属性栏、翻译和标注逻辑。
- 不做文字层内直接编辑；后续如有需要，再单独设计“双击改字/导出”。
