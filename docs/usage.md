# 使用指南

[返回 README](../README.md) · [English](usage_EN.md)

## 启动截图

从菜单栏剪刀图标选择区域、全屏或长截图。默认区域快捷键为 `⌘⇧X`，全屏为 `⌘⇧A`；可在设置中修改。启用双击 Option 手势需要输入监控权限。

全屏截图捕捉鼠标所在屏幕并进入标注编辑。区域截图框选后默认进入“选择／移动”，可在工具栏设置中修改默认工具。外层控制点调整截图范围。

## 标注与属性

选择工具或已有标注，属性栏自动显示对应选项。颜色、粗细、字号及效果参数按工具独立记忆。“恢复默认”仅影响当前工具；修改已有对象可用 `⌘Z` 撤销。撤销恢复画布对象，明确修改过的下次使用偏好仍保留。

- **矩形／椭圆／箭头／画笔**：空白处拖动绘制；矩形属性提供圆角 0、4、8、16、24、32，0 表示直角。圆角随小矩形尺寸限制，不超出短边的一半。
- **选择与调整**：点击已有标注选中，矩形和椭圆请点击边框。选中后拖动移动，拖动控制点缩放，箭头可调整首尾。`Delete`／`Backspace` 删除选中项，`⌘Z` 撤销。点击选择／移动，或再次点击当前工具，返回选择模式。
- **文字**：点击文字工具，再点图上位置就地输入；回车换行，点击空白处提交。选中文字后拖动右下角手柄缩放字号。
- **序号**：点击放置递增数字。支持实心／描边、字号，以及边框／填充／数字独立颜色；先选择颜色对象，再用共用色板调整。描边模式隐藏填充项；实心可选“无边框”；数字可恢复自动配色。切换模式保留原填充设置。
- **改号**：关闭“框选后双击完成截图”后，双击文字或序号可编辑。序号范围 1–9999，回车确认、Esc 取消改号；改成 N 后下一编号为 N+1。拖动右下角手柄缩放。删除最近创建或改号的序号可回退下一编号，删除中间项不重排其他编号。
- **马赛克／模糊**：属性栏切换涂抹或框选，调整笔刷大小、颗粒或模糊强度；松手后可继续补涂。编辑旧笔迹先切换选择／移动。

## 完成、复制与保存

双击选区、回车或 ✅ 完成截图，遵循“完成截图时自动保存”开关。新用户默认关闭，仅复制到剪贴板；升级保留原选择。开启后完成截图同时复制和保存。

- `⌘S`／保存：始终写入设置中的保存目录，不受自动保存开关影响。
- `⌘⇧S`／另存为：打开保存面板，默认定位预设目录，可改名或选其他位置。
- 自动保存失败时提示错误，截图仍保留在剪贴板。
- 区域截图保存后结束当前会话；全屏标注窗口手动保存后保留编辑。
- `Esc` 取消截图，包括正在输入文字时；正在改序号时先取消改号，再按一次取消截图。

设置中可关闭双击完成，恢复双击文字／序号编辑；空格可设为关闭（默认）、完成或保存并复制。文字输入期间空格与回车仍用于输入。

## 贴图与长截图

点击图钉将截图置顶，可拖动位置，双击关闭。

长截图可从菜单栏或截图工具栏启动。框选目标区域后滚动，保留相邻画面的重叠内容；回车完成，Esc 取消。默认进入可滚动、缩放的标注窗口，也可在设置中关闭“完成后进入标注编辑”，改为先预览再复制或保存。

## OCR 与翻译

OCR 识别截图文字，在结果窗口中查看、复制或翻译。翻译需 macOS 26+；缺少语言包时系统提示联网下载，安装后可离线使用。取消下载后可重试，已确认的下载可能在后台继续；语言包在“系统设置 → 通用 → 语言与地区 → 翻译语言”管理。

“原图翻译”把译文回贴到原文字位置，支持校正单个译文、切换原图／译图、复制、保存和继续标注。过长译文需缩短或排除对应区域后才能导出。复杂底纹、表格及特殊字体需要人工核对，不保证无痕还原。

截图、OCR 和翻译文本在本机处理；首次下载翻译语言包与检查更新需要联网。

## 设置

从菜单栏打开设置，或在 LibreShot 激活时按 `⌘,`。可调整保存目录、自动保存、登录启动、截图圆角、快捷键、Option 手势、双击完成和空格动作。

工具栏页可显示／隐藏工具、拖动排序或用上下箭头调整，设置编辑快捷键和默认工具。完成和取消始终显示；配置从下一次截图生效。隐藏默认工具会回退选择／移动，“恢复默认”恢复工具显示、顺序及默认工具。
