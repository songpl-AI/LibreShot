# 1.3.7 后新增 Issue 对比评估

审阅日期：2026-10-06。对照当前源码（HEAD cf1dddd）及公开 1.3.7 build 29，读取 GitHub 当前开放的 [#17](https://github.com/songpl-AI/LibreShot/issues/17)、[#18](https://github.com/songpl-AI/LibreShot/issues/18)，并查看 #18 的竞品参考图。本次只评估，不修改程序、打包或更改 Issue 状态。以下代码结论来自静态核对，未宣称已在本机复现报告者的全部操作。

## 结论与优先级

建议先修复操作问题，再吸收局部视觉设计。竞品值得借鉴的是清晰的状态、可拖动的选框与醒目的标注，不需要照搬整套工具栏。

| 建议 | 当前差异与收益 | 优先级 / 难度 | 建议方案 |
| --- | --- | --- | --- |
| 文字二次选中、三指拖动 | 已选中文字可拖动；未选中文字在文字工具下拖动超过阈值时，事件被处理，却未完成选择或移动。点中失败后也可能新建文字。影响常用操作，收益最高之一。 | P1 / 中 | 先复现点击、三指拖动、重叠文字及编辑器内选字。命中已有文字时，轻点选择、拖动选择并移动、双击编辑；仅在空白处轻点新建。统一按下时命中判定，保持原生编辑器选字与缩放手柄优先级。 |
| 访达底部回弹、向上回看 | 当前匹配仅接受向下位移；末帧未接上会阻止导出，回到最后接受位置可解除提示，但需要像素完全相同。底部回弹可能触发这一限制。修复可提高成功率。 | P1 / 中到高 | 先识别可信的短暂反向位移、回到已捕获内容及稳定恢复；不重复追加，也不把异常帧换成拼接基准。保留真实缺帧的失败保护。稳定后再结束，必要时明确显示等待恢复的状态。 |
| 实心序号、浅色数字 | 现有序号为描边圆圈和同色数字，颜色已经可选，并非只能红色。新增实心样式可改善复杂背景上的辨识度。 | P2 / 中 | 增加“描边 / 实心”样式；填充采用用户所选颜色，数字采用有足够对比度的浅色或深色。同步显示、编辑、导出、缩放、撤销及下一序号样式继承；不强制所有工具变蓝。 |
| 箭头尖端 | 目前为固定长度 15 的开放 V 形箭头；参考图的小实心尖端更明确，但美观有主观性。 | P2 / 低到中 | 先比较开放式与实心尖端效果；头部尺寸随线宽和箭头长度调整，避免短箭头头部过大。共用几何计算，统一预览、导出与点击命中区域。 |
| 文字选框外观 | 当前已有蓝色编辑边框和缩放功能；参考图强调较清晰的边框与控制点。主要是状态识别与视觉改进，无需重写文字编辑器。 | P2 / 低到中 | 在交互修复后微调圆角、边框、控制点与间距，区分选择态和输入态；保持文本锚点、字形、尺寸以及导出结果一致，编辑辅助框不导出。 |
| 从初始位置向上扩展完整长截图 | 当前仅追加下方新内容，没有向顶部追加和全局位置管理。与兼容回弹是不同需求。 | P3 / 高 | 若以后确认需要，再独立设计双向坐标、顶部追加、重复区去重与固定区域处理。本轮不为回弹问题扩展到完整双向拼接。 |

P1 表示下一轮先处理，P2 为有收益的后续改进，P3 为独立专项。没有证据需要紧急 P0。

## 代码依据与验证边界

- `LibreShot/Features/Overlay/OverlayViewModel.swift`：`handleAnnotationPressChanged/Ended` 使用 5 点拖动阈值；未选中的文字/序号候选超过阈值后没有选择或移动动作。`handleSelectedShapeDrag` 已支持选中后移动，不能笼统认为所有文字都无法拖动。命中遗漏导致新建的具体条件需要复现，不能直接认定三指手势是唯一根因。
- `LibreShot/Features/Overlay/OverlayView.swift`：新建文字等待释放时判定轻点；已有文字布局和原生编辑器在 1.3.7 已统一。应在这一基础上修交互，不撤回已完成的排版一致性修复。
- `LibreShot/Editor/EditorToolbarView.swift`：已有预设颜色和更多颜色选择；`OverlayViewModel.selectedColor` 初始红色。#18 的样式收益主要是实心填充，而非新增颜色能力。
- `LibreShot/Features/Overlay/OverlayView.swift`、`LibreShot/LibreShot/CaptureService+Annotation.swift`：序号圆圈描边，数字同色；箭头为开放 V 形。模型命中测试位于 `LibreShot/Editor/Annotation.swift`，修改外观时需要一并核对。
- `LibreShot/LibreShot/CaptureService.swift`：`LongCaptureOverlapMatcher` 仅搜索正位移；`LongCaptureFrameAccumulator` 在末帧不匹配时拒绝最终导出；去重器只以完全相同像素判定返回最后已接受位置。以上解释了反向滚动不受支持，但访达回弹的具体帧序列仍需复现。

## 建议执行顺序与验收

1. 文字二次选中与拖动：覆盖鼠标、触控板三指拖动、不同字号、多行、重叠文字，检查没有误建文本；编辑器内选字、双击编辑、撤销仍正常。
2. 长截图回弹兼容：覆盖访达底部回弹、短暂上滑后继续下滑、重复列表行、真正缺失重叠区域；核对最终内容没有漏行、重复或错位，不能仅以“不弹错误”算通过。
3. 实心序号：检查各种颜色背景、多位编号、编辑、缩放和导出；保持已有描边样式可用。
4. 箭头尖端与文字选框作为一批小型视觉优化，先看效果再定默认样式。

最小建议范围是前两项；实心序号是最值得吸收的视觉增强。完整双向长截图暂缓。实际实现或安装仍需另按项目安装与授权规范验收。
