## 代码核对入口

- `LibreShot/Features/Overlay/OverlayView.swift`：文字与序号共用 InlineTextEditor，编辑边框统一为圆角矩形；普通文字显示为 medium，序号显示为 semibold。
- `LibreShot/LibreShot/Core/InlineTextEditor.swift`：NSTextView 已将 inset 和 lineFragmentPadding 设为 0，但使用 systemFont 默认字重，并按 usedRect 报告尺寸。不能认定问题仅是内边距；字体/排版路径不统一是可确认的事实，实际跳位幅度尚未在本轮复现。
- `LibreShot/Features/Overlay/OverlayViewModel.swift`：startNumberEdit 仍设最小宽 80、基于 selectionBounds.origin 定位；startTextEdit 基于 startPoint 定位。编号输入和提交逻辑可复用；默认工具、涂抹默认宽 20 和补涂不选中已存在。
- `LibreShot/LibreShot/Core/Storage/ToolbarConfiguration.swift`、`LibreShot/Editor/EditorToolbarView.swift`：长截图仍是 arrow.up.and.down.square、翻译仍是 character.bubble；马赛克/模糊使用新自绘图标。
- `LibreShot/LibreShot/CaptureService+Annotation.swift`：真实效果及平均像素块共用渲染。
- `LibreShot/LibreShot/CaptureService.swift`：LongCaptureStitcher 对整幅宽度裁切追加，已有部分固定底栏处理；不等于任意局部滚动合成。
- `LibreShot/LibreShot/Core/OCR/OCRWorkerOperation.swift`：OCR 独立进程及取消/超时处理。
