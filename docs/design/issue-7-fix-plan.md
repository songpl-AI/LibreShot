# Issue #7 修复计划

来源：[权限 bug #7](https://github.com/songpl-AI/LibreShot/issues/7) 及 2026-09-28 的补充评论。

按用户可感知的故障依次处理，每项完成后单独验证，再进入下一项。

| 顺序 | 功能块 | 验收条件 | 状态 |
| --- | --- | --- | --- |
| 1 | 录屏授权 | 同一进程内拒绝或旧授权失效时，系统授权请求与应用权限说明各出现一次；恢复屏幕读取后重置提示状态。发行打包检查签名身份，避免把临时 ad-hoc 签名当成稳定发行包。 | 源码与打包检查完成；真实 TCC 升级仍需新安装包验收 |
| 2 | 选区工具栏 | 可用按钮在明暗截图背景上均清楚可辨；真正不可用的按钮才呈现禁用样式，交互保持可用。 | 生产视图改为不透明系统窗口背景；原生浅色样例已核对，深色实机待验收 |
| 3 | 圆角截图 | 圆角与直角设置对复制、自动保存、另存为、贴图输出一致；在常见截图尺寸下差异明显，PNG 角像素与边缘像素符合预期。 | 半径由 8 点增至 16 点；像素和剪贴板回归通过 |
| 4 | 原图位置翻译 | 翻译完成后可以直接点击选区图像切换原图和译文；复杂背景/溢出警告、语言选择、重试和校正仍可访问，导出状态明确。 | 点击切换和拖动边界回归通过；原生实机交互待验收 |
| 5 | 使用后内存 | 在相同版本、图片与操作序列下记录启动、截图、标注、翻译及关窗后的 physical footprint。先定位持续占用，再优化被证实的保留对象；不以系统缓存短期未归还判定泄漏。 | 独立 OCR/翻译样例已测；真实应用的 350 MiB 场景尚未复现，未做推测性内存改动 |

验证优先使用现有 `tests/run-toolbar-checks.sh`、`tests/run-issue4-checks.sh`、`tests/run-visual-checks.sh` 和独立内存探针；录屏 TCC、Finder 长截图及不同 macOS 版本还需真实安装版验收。

当前公开 v1.3.0 是 ad-hoc 签名。源码可改善重复弹窗和恢复指引；发行脚本默认要求 Developer ID，对现有 GitHub 临时签名分发提供显式 `--ad-hoc` 模式和权限迁移警告。要让升级后的权限持续有效，仍需用稳定的发行证书签名；Apple 公证还要求 Developer ID。
本机 `security find-identity -v -p codesigning` 返回 `0 valid identities found`，因此本轮无法产出可验证 TCC 迁移的正式签名包。
`bash build_release.sh --ad-hoc /tmp/libreshot-issue7-ad-hoc-smoke` 已完整生成 1.3.0 (15) DMG 并通过签名与磁盘映像校验；这只验证现有 GitHub 分发方式可继续打包，没有安装、上传或验证新版本的真实录屏权限。
提交 `c82f591` 的本地候选包保存在 `dist/LibreShot-issue7-c82f591-local/LibreShot-1.3.0-15.dmg`，SHA-256 为 `97d5371825e38747cd8a2dc3d157dc4cebee3b1832b03605b89be7982b8f4aa2`，应用 CDHash 为 `8e1195ba253ea940d517bb60c29e0b0c89f4b21a`。它与当前安装的 1.3.0 (15) 同版本号但签名哈希不同，仅供本地验收；尚未替换正在运行的应用或发布到 GitHub。

本轮测量：独立优化编译进程的 OCR 五次后 60 秒为 53.8 MiB；OCR→原图翻译→关窗后 60 秒为 80.9 MiB，后者在 15 秒时也是 80.9 MiB。均高于约 5.5 MiB 的空进程基线，但没有观察到关窗后持续增长。旧记录同场景分别为 53.8 和 82.5 MiB；该隔离样例不能代表报告者的真实屏幕尺寸、翻译内容和完整应用链路，也不能据此承诺 10 MiB 闲置目标。后续针对完整应用应使用固定截图/操作序列和有分配栈的构建定位保留对象，见 [已有内存拆分](../qa/feature-memory-profile-20260926.md)。

同进程压力样例连续编辑/复制 20 次，在最后一次操作点约 323.8 MiB，闲置 15/60 秒约 90.4/90.5 MiB；这说明高峰读数不能直接当作持续泄漏。随后连续 OCR 五次在操作点约 151.2→164.6 MiB，增幅趋缓，闲置 60 秒约 138.2 MiB。相较复制/编辑阶段，OCR 后的常驻增量约 47.7 MiB；当前源码每次创建并释放 Vision 请求，这个测量不能证明具体系统缓存的所有权。
