## 第一批：完成贴图定位与滚轮契约（#35、#32、会话快捷键）

### 定位

沿用已经实现的源全局矩形与逻辑尺寸，不重新读取活动窗口屏幕来决定普通区域贴图位置。没有源矩形的图片文档使用当前文档屏幕回退，长截图预览适屏展示。

补实机矩阵：台前调度开／关，区域截图在主屏／外接屏，截完后将其他屏幕上的应用切到前台，再按钮／⌘P 贴图；验证第一次显示位置、Retina 点像素比例、负坐标屏幕、全屏 Space 和多张贴图。先验证具体报告，不因报告提及台前调度就随意改窗口 collectionBehavior。

### 滚轮行为

推荐保留维护者已批准的普通滚轮缩放，同时明确支持 Issue 的修饰键，避免重新增加使用门槛：

| 指针位置与输入 | 行为 |
| --- | --- |
| 普通贴图图像区域，无修饰键＋滚轮 | 缩放，保留已批准的操作 |
| 普通贴图图像区域，⌘＋滚轮 | 同一套鼠标锚点缩放 |
| 普通贴图图像区域，Control＋滚轮 | 调整贴图显示透明度，不改变尺寸／位置 |
| 普通贴图图像区域，触控板捏合 | 同一套锚点缩放 |
| ⌘和 Control 同时按下，或其他未定义组合 | 不调整透明度或缩放，避免猜测意图 |
| 属性滑块区域，无修饰键＋滚轮 | 若属性滚轮功能获批，仅修改命中的参数，不缩放窗口 |
| 菜单、文字输入框或其他控件 | 保留控件原有处理，不同时触发贴图操作 |
| 长截图采集／图片文档滚动区域 | 保留原采集／滚动行为，不拦截为贴图缩放 |

如果后续要改成“只有 ⌘＋滚轮才能缩放”，应作为明确的交互变更另行确认，不能在合并需求时悄悄删除普通滚轮功能。

将透明度从图片视图私有 `@State` 收敛为每个贴图窗口共享的可观察状态，右键预设与 Control＋滚轮访问同一个值。建议范围 10%–100%，鼠标每档 5%，精细滚动累积处理；限幅且忽略惯性。只改变图像显示透明度，菜单／编辑控件保持可读，复制／保存的原图 Alpha 与分辨率不变。此比例是待实施的设计值，需要实际鼠标／触控板体验确认。

默认 ⌘P 沿用当前实现，输入框保护、冲突检查、旧绑定保留和恢复默认规则不变。

影响：小到中。现有位置与缩放源码继续利用，新增透明度状态和修饰键分派；安装前补控制键矩阵与原图一致性检查。

## 第二批：工具栏左／中／右对齐（#34）

在工具栏设置页增加“位置：左／居中／右”，默认居中，持久保存，旧配置保持现状。左对齐用主工具栏左边缘对齐选区左边缘，右对齐用主工具栏右边缘对齐选区右边缘；不能按较宽的属性面板边缘替代主工具栏边缘。

屏幕边界容不下时以整体可见为优先，保持现有上／下翻转和窄屏换行。工具栏绘制、属性附属区、悬停提示及画布事件排除范围必须使用同一份布局结果，避免只移动按钮、旧位置仍拦截点击的错误。

第一版作用于区域截图浮动工具栏，图片文档底部固定栏保持现有布局。以后贴图编辑工具栏可复用同一偏好，但不让显示偏好改变贴图图像位置或输出内容。

影响：中小，主要是布局和设置。验收四角、小选区、工具排序／隐藏、多行栏和属性面板较宽时的实际对齐与命中。

## 第三批：贴图右键后原地编辑（#33）

这是一项真正新增的编辑能力，不能只把长截图预览的回调复制过来：当前普通贴图图像已经合成，旧文字、形状和效果没有独立数据，无法从位图可靠还原。

推荐目标：右键菜单增加“编辑标注”，进入当前贴图的编辑模式；复用现有工具与属性界面。工具栏可放在邻接的浮动面板中，避免给小图增加内边距或把原贴图位置挤走。需要“应用”与“取消”，并保留复制／保存入口。

为后续生成的贴图保留“裁剪后的原始底图＋选区局部坐标标注＋当前全局贴图位置”的文档状态。保留裁剪后的底图即可，不继续持有整屏图像。标注只在显示／导出时合成，使已有对象仍能选择、修改、撤销；反复编辑不把马赛克／模糊一层层重复烘焙。

对于导入图片或本来就是合成位图的来源，可继续添加新标注，但旧像素内容不能作为独立对象重编。此边界应在文档里明确。

进入编辑模式时，暂停双击关闭，避免与文字／序号双击编辑冲突；绘图优先于窗口背景拖动，原截图的双击完成规则不能直接触发贴图关闭或自动保存。工具栏命中处的滚轮只调整控件，图像区域遵循已定义的缩放／透明度规则。

应用后更新同一贴图，保留其当前位置、显示大小与透明度；取消则回到进入编辑前的内容。不重新居中，不把显示缩放比例写入保存图片。关窗应释放文档、编辑器和异步预览；多张贴图相互独立，并补重复打开／编辑／关闭的内存检查。

“右键→在独立图片编辑器中打开”可以作为更小的过渡方案，但不是 Issue 要求的原地调出工具栏，不能把过渡方案描述为完整满足 #33。

影响：中到高，涉及文档数据、输入模式与结果回写，建议独立实施和验收。#34 的布局偏好、#32 的输入分派可供这一阶段复用。

## 相关独立项：属性滚轮（#22/#29）

不与贴图窗口缩放共用一个粗放的全局事件处理器。只有指针在指定属性控件上，且没有在精确输入／系统取色器中操作时，才调该参数；文本字号、线宽、圆角、颗粒等按各自单位设置步长和边界。一次连续滚动应形成一个撤销步骤，既有参数记忆和当前对象／下一笔的作用范围保持一致。

先实测原生 Slider 是否已改变值，防止再加一层造成同一次滚轮变动两次。补当前值提示和可滚轮调整的反馈即可。建议保留现有标签与精确输入，不直接按评论删除；常用区间可以更细致，但不要缩窄模型硬范围、破坏已保存的值。颜色简化、属性自动隐藏、阴影预设等属于 #22 的其他建议，另行评估，不混入这一轮贴图工作。
