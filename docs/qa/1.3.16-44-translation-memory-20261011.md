自然采集结束后，对准确PID40601执行10秒Allocations + VM Tracker + Virtual Memory Trace附加烟测。退出码2，明确“Failed to attach to target process”；虽生成trace和TOC，TOC没有有效malloc allocation/backtrace表，不能说已采到长图分配栈。原始command/record.log/exit/trace-toc位于 `trace-attach-smoke-01`。失败根因不能仅凭这个泛化错误认定为某项系统权限；本机开发者模式与签名事实保留，未改签名/保护或追加权限。
