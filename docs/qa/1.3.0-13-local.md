## 正式版人工试用内存采样（2026-09-27）

用户在已安装的 1.3.0 (13) 上试用期间，对同一进程 PID 27592 以 `vmmap -summary` 约每 6 至 8 秒采样一次，共 120 次、15.1 分钟。原始记录为 `dist/memory-profile-release-20260927-live-processes.csv`，采用 physical footprint，不与 Activity Monitor 的 RSS 混用。采样开始前进程已经运行，41.6 MiB 是本轮起点，不是冷启动值。

| 时点 | LibreShot physical footprint |
| --- | ---: |
| 本轮开始 | 41.6 MiB |
| 采样峰值（开始后约 95 秒） | 174.0 MiB |
| 开始后约 110 秒至 7.5 分钟 | 约 105.3 MiB |
| 7.5 至 15 分钟 | 约 101.1 至 101.4 MiB |

用户确认 OCR、文字翻译、原图对照翻译、长截图四项均完成，长图显示正常，结果窗口均已关闭。因此，这轮没有观察到操作结束后继续线性上涨，且从采样峰值回落约 77 MiB；但结束后仍比本轮起点高约 55 MiB。现有记录没有逐项操作事件或关窗时间，无法把峰值归因于 OCR、翻译或长截图，也不能凭一次留存值判定泄漏或系统缓存。`vmmap` 的进程生涯峰值为 213.0 MiB，可能发生在本轮以前，不能当作本轮采样峰值。系统翻译进程单独记录：`translationd` 本轮最高约 63.3 MiB、结束约 62.8 MiB；`TranslationAPISupportExtension` 最高约 16.8 MiB、结束约 16.7 MiB，不能全计作 LibreShot 独占内存。长截图的正常输出为用户目视确认，本轮没有程序化记录拼接帧数或成图高度。
