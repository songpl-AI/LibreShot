# LibreShot 1.3.18 build46：无标注长图导出内存

2026-10-11。本次只优化编辑器中来源明确的无标注长图保存/复制；不修改长图匹配算法、OCR worker 或翻译服务。未提交、推送或发布。

## 修改及限制

旧编辑器即使没有标注也会规范化整图，然后再绘制一份整图。现在只有长截图两个进入编辑器的入口携带来源证据，且原图为稳定单一 sRGB、8bit、32bpp、1x/2x 表示时，保存、另存、复制、保存并复制可复用原背景。文字先提交，再检查资格。有标注、绘制手势、未完成文字/序号、译图、替换底图、部分选区或未知来源，均继续原路径。圆角处理和 PNG/TIFF 编码不变。

新增 backing 只共享原 CGImage，不复制像素；窗口关闭时与原图、模型一起撤引用。生产 renderer 供真实控制器与无窗口实验共用，避免探针测试另一套假设实现。

## 实际框选覆盖范围与后续重点

额外只读复核发现，真实长图并不保证严格1x/2x比例：`LongCaptureImageSampling.pixelRect` 将物理crop向外取整，但`LongCaptureSession.finish`仍以原始CGFloat框选宽度设置NSImage逻辑宽度，并按输出像素比例设置高度。因此自由框选的物理宽度不一定等于原逻辑宽度×1/2；当前资格检查会安全回退，footer只改变高度，不消除这一宽度偏差。

圆角绘制保留像素宽高与逻辑size，编码DPI直接使用pixels/logical×72。本轮约144.12DPI提示可能存在非标准比例；没有原始NSImage/资格事件，仍不能确证本轮是否回退。当前收益覆盖符合资格的长图，实际自由框选命中率尚未知。下一步应先通过离线真实Session交接公式的fractional几何案例明确行为，再设计保持旧像素和DPI兼容的优化；不能为命中率直接放宽资格或改变逻辑尺寸。此次未因此重编、重新安装或让用户重复截图，已验收包保持不变。
