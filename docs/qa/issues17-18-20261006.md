# Issue #17 / #18 实现与源码验证

日期：2026-10-06。候选版本 1.3.8 build 30，暂未发布。

## 实现

- 文字/序号工具下，直接拖动未选中的文字/序号会选择并移动该对象，保持按下位置与撤销；拖动不计为双击。创建文字入口再次检查命中，避免命中已有对象却新建输入框。编辑器内开始的选字拖动不会因移出框外立即提交。
- 长截图增加反向匹配判断：在与最后已拼接画面仍有可信重叠、且反向距离位于已捕获范围内时，视为回看，不追加、不替换前向基准；继续向下从原基准拼接。方向歧义、无重叠和初始位置上方未捕获内容仍提示失败。本轮不是无限距离回看或向顶部扩展的完整双向拼接。
- 新建序号默认实心，可在颜色与字号面板选择描边。记住样式，支持选中修改、编辑、下一序号继承及撤销。深色填充使用白字，浅色填充使用黑字；仍由用户选择填充颜色。
- 箭头使用共享实心尖端几何，头部随线宽调整且限制短箭头头部比例；显示、导出、命中和选区边界统一。
- 文字选择框圆角、边框清晰度与编辑框间距微调；输入框辅助边框不抢鼠标事件，也不写入导出图。

## 复现与回归
