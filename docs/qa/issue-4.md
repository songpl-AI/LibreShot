# Issue #4 验收记录

范围：圆角、长截图拼接、翻译栏与复制译文、保存/另存为快捷键、回车完成、长图标注。双击 Option 与完整快捷键配置暂不实现。

## 根因与实现

- 圆角：历史截图服务重写后只剩设置；恢复导出样式处理并保留 Alpha，贴图也应用同一轮廓，OCR 继续读取未遮罩内容。
- 拼接：背景主导的评分和纵向降采样都可能让重复行匹配到错误周期。现在只压缩横向，按原始像素行搜索位移，再逐行验证多个候选并拒绝歧义；固定底栏根据稳定的水平边界识别，20/32 px 薄底栏也只保留一次。
- 帧筛选：ScreenCaptureKit 完整帧在连续滚动时直接参与匹配，不再等待停稳而丢掉中间重叠帧。只有拼接成功才更新去重基准；失败可回滚重采，结束仍有未匹配画面时明确报错，不把首帧当作完整长图。录屏使用屏幕物理像素尺寸，结束时排空串行采集队列。
- 翻译栏：原文复制与翻译控制分行，翻译加载时保持宽度；译文区域独立复制并反馈成功，保留原文 ⌘C 快捷键。
- 长图：复用标注模型与渲染，工具栏固定，文档禁止移动/缩放选区；缩放在 SwiftUI 内完成以保持事件坐标一致，保留图片像素和逻辑尺寸。内联文字不触发外层画布自动滚动。

## 原生窗口实测（2026-09-14）

独立 QA App 使用生产 `ImageEditorWindowController` 与合成 60 行图片，不要求录屏授权。

1. 初始显示 100%，从第 1 行开始，工具栏完整可见。
2. 缩小到 80%，滚动到第 39–60 行，工具栏固定在顶部。
3. 点击第 47 行右侧，文字编辑器在点击处出现。
4. 输入 `Bottom annotation`，回车后输入 `Second line`；视口位置保持不变，文字完整。
5. 按 ⌘S：提交标注，保存成功，编辑窗口保留。
6. 按 ⇧⌘S：进入独立另存为动作。
7. 未编辑文字时回车：执行完成动作并关闭窗口。
8. 输出 PNG 保留 1400×4800 像素。测试文件保存在临时目录，不改用户剪贴板。

原生渲染另验证了 480 点宽 OCR 窗口：长原文、复制原文按钮和翻译行均完整显示。
