# 马赛克首次涂抹偏移：源码修复与验证

日期：2026-10-11。基线 HEAD：0f1b715。本轮仅修改源码与回归检查，未构建试用包、替换应用、恢复授权或发布。

## 原因与修改

`OverlayViewModel.scheduleEffectPreview` 把选区乘缩放比例后用 `integral` 扩展到整数像素边界，但此前仍按未取整的选区平移标注，并把原选区尺寸传给渲染器。实际裁剪尺寸、渲染比例和回贴位置不一致，导致首次有效涂抹启动局部预览时，连预览包围框内未涂抹的源像素也会错位。

现在裁剪、标注平移、逻辑尺寸、局部输出范围和回贴位置均基于实际源像素边界计算，并在转换 Core Image 的上下方向时使用实际裁剪高度。保留选区裁剪、局部输出及单任务异步渲染方式。

这能解释特定选区或缩放下的首次预览跳动，不代表已经确认反馈用户的版本和操作条件，也不代表问题只影响第一笔。纯点击／不足绘制阈值的抖动不会生成有效预览。

## 回归测试

在 `Tests/EffectRenderingChecks.swift` 增加生产绘制入口的首次预览对齐测试：

- 480×320 双轴位置编码图，避免纯色或单方向条纹掩盖错位。
- 马赛克、模糊，两种工具均使用首次有效涂抹，松手前检查预览。
- 1×、1.5×、2× 缩放；整数选区、原点与尺寸均为小数、仅尺寸为小数，共 18 组。
- 校验回贴框对齐源像素网格、尺寸保留原比例，并逐像素比较笔迹包围框中远离涂抹路径的未处理区域。

命令：`bash tests/run-effect-checks.sh`。

修复前在 `mosaic, 1.0, (25.3, 19.7, 170.4, 120.6)` 处按预期断言失败（退出码 133）；修复后新增检查和原有效果回归均通过（退出码 0）。原有测试覆盖连续拖动、预览与导出一致性、块平均与网格稳定、笔刷／强度、重叠、Retina、透明度、长图局部输出、撤销和会话关闭隔离。
