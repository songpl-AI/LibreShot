# LibreShot build 90 → 91 译图导出内存对照

2026-11-22。build 90 来源为 `38d39db`，build 91 为 `bc57ba0`。均为在 `/Applications/LibreShot.app` 固定路径正常启动的完整 ad-hoc 安装包。build 91 对像素整齐对齐的译图选区直接合成，把原来的整屏合成与裁剪缩为一次选区渲染。几何不匹配时沿用整屏路径。

M2 Pro、16 GiB、macOS 27.2.1 (26B131)、单屏 3024 × 1964 Retina。各轮选择同一 2048 × 1280 像素公开素材，系统翻译为英文至简体中文。用同一份探针，每个版本每项运行三个独立新进程。四种场景分三组轮换顺序。纯复制测试临时关闭自动保存，使用完毕后恢复原配置与剪贴板。24 轮全部成功，共记录 83,029 个采样点。

## 实测结果

表中为三轮中位数，主进程 physical footprint，单位为 MiB。导出阶段取触发保存或复制到初次验证前的采样峰值。全程内核峰值取同一进程截至导出结束的内核累计值，因此能覆盖采样间隔内的短峰值。关窗一分钟取第 55–60 秒采样中位数。

| 场景 | 全程内核峰值 | 导出阶段采样峰值 | 关窗一分钟 | 关窗后再次截图 |
| --- | ---: | ---: | ---: | ---: |
| 普通截图后保存 | 151.06 → 151.03 | 141.11 → 141.80 | 39.56 → 39.36 | 194.08 → 173.83 ms |
| 普通原图选区复制 | 152.31 → 152.14 | 152.19 → 152.14 | 39.08 → 39.14 | 243.95 → 195.10 ms |
| 译图后保存 | 160.69 → 141.14 | 135.70 → 108.92 | 70.41 → 70.16 | 239.64 → 198.42 ms |
| 译图后复制 | 160.14 → 141.39 | 137.56 → 123.33 | 70.72 → 73.20 | 181.11 → 199.34 ms |

译图后保存的导出峰值降低 26.78 MiB（19.7%），全程内核峰值降低 19.55 MiB（12.2%）。译图后复制的导出峰值降低 14.23 MiB（10.3%），全程内核峰值降低 18.75 MiB（11.7%）。两项新版导出峰值的最高一轮均低于旧版的最低一轮。普通保存和复制两个对照的关窗与峰值读数接近。

关窗占用暂未显示稳定下降。译图保存新版逐轮为 60.33、70.22、70.16 MiB，旧版为 70.41、70.47、70.38 MiB。译图复制新版逐轮为 90.80、73.20、70.61 MiB，旧版为 70.72、70.39、71.74 MiB。新版复制的中位数高 2.48 MiB，首轮值更高。新版复制再次打开截图遮罩的三轮范围为 173.48–230.32 ms，旧版为 175.86–209.20 ms，两组范围重叠。

对新版译图复制另用新进程做一次五分钟复测。关窗第 1、2、5 分钟的中位数均为 73.81 MiB。第 2 分钟之后采集的 VM 快照显示 73.8 MiB footprint，`DefaultPurgeableMallocZone` 约有 23.2 MiB 脏页。离屏剪贴板测试的六对 PNG/TIFF 字节相同，走选区路径后五秒占用中位数也未复现实机首轮的上升。实机较高读数的成因尚未定位，五分钟复测作为额外证据单记，保留原三轮对照。

## 功能校验与归档

- 四个场景在两个版本的实际导出像素指纹一致。纯复制每轮均验证系统剪贴板 PNG、LZW TIFF 与 AppKit 实际读取像素一致。纯保存每轮核对实际写盘及剪贴板序号。
- build 91 从应用菜单启动真实截图并保存带画笔的公开素材。正常重启同一个安装副本后，自动化双击 Option 触发并再次保存。两份证据均为 480 × 280，分别通过录屏与输入监控验收，实体双击 Option 待验。
- 选区像素和回退边界测试、普通导出 33/33、长图编辑导出 449/449、译图生命周期检查通过。离屏测试的 36 对位图像素一致。运行旧版生命周期套件复现了旧断言的问题，该测试已按实际工具栏开关行为修订，见 `a82895b`。
- 持久证据在与工作树并列的 `LibreShot-memory-evidence/`。其中 `matched/comparison-90-91.json` 含两个版本每个场景的逐轮结果、范围和百分比，`matched/build-{90,91}/run-*/` 含原始 CSV、过程日志和输出 PNG，`matched/build-91/copy-five-minutes/` 含额外采样和 VM 快照。两版 DMG、SHA 校验、测试脚本与验收样本分别归档。此前 [build 90 五分钟记录](1.3.34-90-idle-memory-study.md) 与 [连续使用十项功能记录](1.3.34-90-feature-memory-baseline.md) 保留各自的测量条件。
