# Issues #4–#6 开发版验收

日期：2026-09-20 至 2026-09-21。环境：Apple Silicon，macOS 26.5.2，Xcode 26 SDK。基线 `71fb0d2`，此次仍为未发布源码，不修改已安装应用，也不关闭 GitHub issue。

## 已实施

- 区域截图与长图编辑器共享工具动作和快捷键；编辑快捷键独立持久化，冲突/保留键校验，恢复默认，录制器关闭时移除监听，同一时刻只有一个录制器活动。
- 空格可选关闭、完成或保存并复制；输入文字期间不拦截字符/空格/回车，保存可提交尚未完成的文字。
- 双击 Option 使用按需创建的被动事件监听，默认关闭；需输入监控权限。两次完整短按、同侧按键、时限、组合键/鼠标/滚动干扰均参与判定，不重置活动截图会话。
- 工具栏保留 32 点按钮、自定义顺序与可见性，减少独立按钮边框，增加悬停和明确的完成按钮。快捷键提示随配置更新。
- OCR 保留区域 ID、位置、置信度和行数，在后台串行队列识别；按行和列排序，不自动跨行合并，避免擦除表格分隔线。批量翻译按 ID 回填，取消、失败、重试、语言切换和过期会话分别处理。取消识别会传递到实际 Vision 请求。
- 原图翻译使用 CoreText 在原区域排版，保留图像物理尺寸与逻辑尺寸；背景取样、字号适配、高对比文字，未变更的文字保持原像素。可切换原图、校正译文、复制/保存图片和继续标注。
- 过长或为空的译文保留原区域并提示，禁用导出直到修改或取消勾选。复杂背景提示核对；不承诺无痕消字、原字体、彩色字样的精确还原。超大图片有分配上限。
- 马赛克辅助位图从每次截图预分配改为首次选用马赛克时分配，重置时释放。

## 内存结果

口径：`task_info(TASK_VM_INFO).phys_footprint`，同一 2400×1400 像素合成图，保留私有剪贴板内容，20 次创建/关闭生产编辑器并复制，随后 5 次 OCR。采用 `swiftc -O` 的隔离进程，包含 AppKit/SwiftUI 编辑器，**不等于完整应用**。基线和当前版本分别独立运行一次，不能据此推导普遍收益或峰值。

| 采样点 | 基线 `71fb0d2` | 当前开发版 |
| --- | ---: | ---: |
| 20 次编辑/复制后 | 85.5 MiB | 97.9 MiB |
| 再闲置 5 秒 | 72.2 MiB | 64.1 MiB |
| 再闲置 60 秒 | 63.6 MiB | 63.8 MiB |
| 5 次 OCR 后 | 137.6 MiB | 140.0 MiB |
| OCR 后再闲置 60 秒 | 101.7 MiB | 108.3 MiB |

结论：未观察到连续编辑后无限增长，但本轮没有证明 OCR 后常驻占用下降；OCR 后样本甚至略高。按需位图消除了未使用马赛克时的这份分配，并不能等同于整个进程降低相同数值。后台识别改善的是 UI 响应，不宣称它降低模型驻留。

最终 Release 应用沿用已有设置的冷启动闲置测量，使用 `tests/profile-idle-app.sh` 和 `vmmap -summary`，15/60 秒约 15.1/15.0 MiB，CPU 采样均为 0.0%；它没有执行截图/OCR，不能与隔离进程的功能使用后数据混用，也不能据此宣称所有功能用完后回到 10 MB。当前未取得可信的系统能耗/唤醒次数测量。
