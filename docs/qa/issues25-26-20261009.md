# Issue #25 实现与 #26 全屏调查

日期：2026-10-09。基线 `b11231e`，候选版本 1.3.11 build 33。维护者授权先处理 #26/#25，并明确要求双击确认适用于所有标注工具。

## #25 实现

- “框选后双击完成截图”默认开启，开关位于快捷键设置并持久化。关闭后恢复原来文字/序号的双击编辑。
- 双击选区在第二次鼠标按下时优先执行 `confirmCopy()`，沿用完成按钮的文字提交、复制与自动保存路径；不依赖当前工具，也不限制空白处。工具栏/属性弹层继续按自身操作处理；未框选与长截图采集阶段不触发。
- 首击可能放置的序号用现有撤销记录回退，再执行完成，不生成多余数字。普通点击、绘制和拖动没有新增等待。已经输入的文字通过现有完成路径提交。
- 只有第一击已经处于编辑阶段、没有实际拖动，第二击才可确认，避免刚框选或拖动后一次点击被系统 clickCount 误判为确认。观察器跟随视图安装/移除，不注册全局鼠标监听，也不增加权限。
