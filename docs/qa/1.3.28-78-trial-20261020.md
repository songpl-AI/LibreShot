## 本次改动

- 未选中时：底部按钮显示“复制全部”，`⌘C` 或 `Return` 复制全部识别文字，并提示“已复制全部 N 行”。
- 选中后：按钮显示“复制”，只复制选中行；`⌘C` 或 `Return` 同样只复制选中行。
- 鼠标移到识别行上：浅蓝高亮，明确可点。
- 窗口布局、图层/列表切换、双击单行复制、`⌘A`、`Esc` 均不变。

## 交给用户验证

1. 打开 OCR 后**不点任何行**，直接按 `⌘C`：应复制全部文字，底部提示“已复制全部 N 行”。
2. 点一行选中，再按 `⌘C` 或 `Return`：只复制这一行。
3. 拖拽/`⌘A` 多选后复制；双击单行复制；`Esc` 关闭。
4. 鼠标在文字行上移动，应有浅蓝高亮。
5. 切到“列表”确认原全文/翻译入口仍在。
