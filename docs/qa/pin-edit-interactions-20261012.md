# 贴图编辑期间移动、双击保存与收起入口

用户在 1.3.18 build 46 上反馈：编辑时无法移动贴图、空白区双击保存被禁用、只能右键结束编辑才能收起工具栏。用户已明确接受：选择/移动工具下空白拖动移动整张贴图；绘图工具继续拖动绘制，另提供工具栏拖动入口。

## 根因与修改

- 编辑开始设置 `isMovableByWindowBackground = false` 以保护绘制，但未补选择工具空白区的窗口移动；现在保留绘制隔离，添加空白画布移动回调。点击已有标注及控制点仍编辑标注，空白处显示移动光标。
- 整图移动保持底图、标注本地坐标、缩放和透明度；使用屏幕指针差值计算窗口位移，避免窗口本身移动导致 SwiftUI 本地拖动坐标变化、抖动。工具栏随贴图重新定位，可跨屏移动。
- 贴图模型禁用 `allowsCaptureCompletion`，同时禁用了共享双击空白判断。修复前原生回归确实在“编辑时双击空白应可用”断言失败；现在用单独的 `onBlankDoubleClick` 保存回调，不完成截图、不关闭编辑、不改变剪贴板。遵循既有双击开关，排除文字输入、已有标注、控制点及真实拖动；沿用共享判断排除文字/序号首击产生的临时内容。
- 双击保存调用生产 `CaptureService.saveImageDirectly`，将当前标注后的 PNG 写入预设目录。保存期间合并重复请求，目录授权恢复和错误沿用生产保存链路；保存后编辑及撤销历史保留。
- 工具栏左侧添加可拖动把手，所有绘图工具下均可用；右侧添加下箭头“收起工具栏”，悬停提示“收起工具栏，保留编辑（Esc）”。收起按钮、Esc 和右键结束编辑使用同一保留修改的动作，无应用/取消底部行。

## 验证

- 原生贴图检查通过：空白与控制点/绘制手势隔离；当前缩放下移动及连续拖动原点；窗口移动后本地坐标变化仍由屏幕指针正确驱动；标注不变、工具栏随动。
- 双击保存验证经生产保存服务向隔离临时目录实际写入 PNG，可解码且字节与当前合成图片一致，只写一次、保留编辑状态；临时目录在测试后清理，不写用户实际保存目录。
- 即时编辑、收起后重开撤销、模型释放和 10 次编辑/关闭生命周期回归通过。
- 普通工具栏回归 25 组通过，包括普通截图双击完成/保存开关和真实 PNG 保存；全屏回归 8 组通过，包括生产编辑器转贴图。共同 OverlayView 默认无移动回调，普通截图行为保留。
- 工具栏原生截图已查看，左右把手/收起图标可见，属性栏保留，无底部冗余操作行。

截图及红/绿检查日志位于 `dist/pin-edit-interactions-20261012/`。

本次修改为源码修复，尚未重新打包或替换本机 1.3.18 build 46；实体窗口拖动、双击保存和收起按钮须在后续固定新包上复验。新包安装仍须遵循 `docs/operations/install-and-permissions.md`，源码回归不能替代最终安装包体验。
