## 剩余约48MiB在哪里

19:00:12自然采样已结束，对同一PID执行一次 `vmmap -summary`，之后一次 `heap -s --noContent`；均exit0约1.5秒，前后libproc footprint恒47.82927MiB。下表按互斥REGION行的dirty+swapped近似分组，含换出负担，**不是当前纯RAM或逐函数精确账本**。打印舍入使分组和47.796875MiB与精确footprint略有差异；不能与下方heap/zone容量再次相加。

| 页类别 | dirty+swapped近似 | 能否优化及边界 |
| --- | ---: | --- |
| malloc页与元数据 | 32.66MiB | 最大类别，其中MALLOC_SMALL约29.33MiB。含活分配、allocator碎片和缓存；可继续找不必要引用/临时分配，但现有快照不足以认定全部可释放 |
| 框架/运行时可写段 | 7.47MiB | 含已初始化Swift/ObjC/框架数据。可减少不必要初始化，但不宜在正常使用后强行卸载；不是同等量业务图片 |
| 图形类别 | 5.00MiB | 含CoreAnimation、CoreUI、IOAccelerator、IOSurface等。结束会话及时撤引用有价值，框架缓存仍可能保留；CG image单项只有0.219MiB |
| 栈、页表、共享内存及其他 | 2.67MiB | 约0.798MiB页表、0.328MiB栈，另有系统结构。属于运行成本，除非证明有多余线程/资源，不应为清零破坏功能 |

heap统计的是分配容量：111450个节点、41.73MiB，与上述页表重叠。最大未分类non-object容量31.01MiB；没有MallocStackLogging，不能把它全部叫截图像素、泄漏或归到翻译函数。可识别Swift Metadata约2.32MiB、ObjC方法缓存约1.56MiB。

DefaultMallocZone容量约20.3MiB，dirty+swap碎片约9.28MiB；碎片已包含在其页负担，不能再加到footprint。DefaultPurgeableMallocZone虽显示约21.2MiB allocated，却为0 resident/dirty、仅80KiB swapped；MALLOC_LARGE约14.6MiB虚拟容量全部EMPTY，0 dirty/resident/swapped。**不能承诺再“释放21MiB/14.6MiB物理内存”。** 634.7MiB总region resident包含大量共享只读库映射，也不是应用独占634.7MiB。

类型表未发现直接 `ImageTranslationModel`、译图controller、OverlayViewModel、ImageEditorWindowController、LongCaptureSession/Engine/Store实例；只有设置、快捷键、AppDelegate、CaptureService、stream gate、声音六类应用实例。其对象头合计1120bytes不代表这些实例的完整间接内存。系统 `TranslationSession`、`_LTTranslationSession`、SwiftUI TranslationSessionViewModel仍有小对象；keypath中出现业务类型名字也不代表该模型仍存在。缺少直接实例支持清理已发生，不能证明匿名buffer/闭包或所有路径都无泄漏。
