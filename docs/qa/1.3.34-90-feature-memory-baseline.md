十项功能使用同一主进程 PID 58444，按顺序运行并逐项关窗。常驻状态会受到之前的功能影响。每项选取一轮有效结果，供后续按同样条件对照。应用启动待机和五轮框选取消使用上一份安装版基线，分别为 18.7 和 35.6 MiB，本次流程经过设置及真实保存，保留独立标签。

组合标注导出中的四种笔迹或特效均在预期区域找到像素变化。译图复制的全程最高采样发生在翻译阶段，该阶段包含 OCR、翻译与译图渲染，约 168.5 MiB。复制图片阶段采样最高 155.9 MiB。复制译图和复制原图分别验证系统剪贴板的 PNG、TIFF 和 AppKit 实际读取图像逐像素相同。译图复制的 PNG 与原图内容不同。OCR 识别了 7 行，复制结果验证包含公开素材文字。所有写入剪贴板动作后都恢复了测试前的剪贴板。

译图复制时主进程与其 OCR helper 同一采样点的合计最高约 230.6 MiB，单独译图时约 253.0 MiB。各轮关窗 5 秒后均未再采到该轮 OCR helper。共享系统服务 `translationd` 在本轮观测范围约 9.0–65.6 MiB，末值约 65.2 MiB，供独立对照。

首轮原图复制的剪贴板内容通过同次格式验证，与另一轮单独采屏保存的 PNG 存在少量像素差异，最大单通道差异 9。首轮 OCR 的文字识别通过，自动化未定位到复制按钮。随后按实际完成复制的两轮结果入表，保留首轮原始记录。临时调整的自动保存开关和原图翻译工具显隐已恢复。长截图拼接、多屏和更大的实际屏幕选区另行建基线。

## 复测

把 [BaselineQA.swift](../../dist/LibreShot-1.3.34-90-memory/qa/feature-baseline/BaselineQA.swift) 用 `xcrun swiftc -O -parse-as-library` 编译到临时目录。启动同一安装路径的待测应用，关闭已有编辑或 OCR 窗口。运行探针时给一个新建的空目录作为第一参数。后续参数可选，用于指定单个或多个场景，默认按普通保存、译图复制、译图、画笔、马赛克、模糊、编号、组合标注、原图复制、OCR 文字复制的顺序运行。脚本使用当前配置的快捷键和公开测试工作区，本次保存到用户当前的截图目录。可附加 `SampleShared.swift` 观察系统翻译服务。

用 [summarize.py](../../dist/LibreShot-1.3.34-90-memory/qa/feature-baseline/summarize.py) 汇总目标目录，重点比较全程峰值、功能阶段峰值和关窗约一分钟时的占用。涉及新增驻留的改动使用新进程重复同一场景，确认差异可复现再归因。
