## 交给用户验证

1. 用 `⌘⇧X` 或菜单栏“区域截图”框选公开测试内容，确认遮罩可见；如提示缺少屏幕录制，先退出应用，在“系统设置 → 隐私与安全性 → 录屏与系统录音”移除旧 LibreShot 项，再用“+”添加 `/Applications/LibreShot.app`，重新打开。
2. 绘制矩形、文字或序号后，把鼠标悬停在已有标注上，确认出现描边；选中、画笔和马赛克/模糊笔刷不应误显示。
3. 框选时查看放大镜：读数前应有 `sRGB` 标识；十字辅助线应为蓝色并带白色描边。
4. 完成截图并保存，确认文件可打开；正常退出并重启同一应用，再次截图保存，确认屏幕权限与保存目录可复用。
5. 若使用双击 Option，核对设置仍启用且无输入监控缺失提示，并实体双击测试。
