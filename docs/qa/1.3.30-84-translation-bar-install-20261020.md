## 本次改动

- 翻译控件并入属性条：`译为 [语言 ▾]`、原文/译文、重译、校正、状态行；去掉独立面板和 ❌。
- 再点工具栏“翻译”图标关闭翻译并保留原图。
- 状态文案去掉“排版”术语：`正在生成译文…`、`翻译完成，点选区可切换原文/译文`。
- 语言选择使用真正的菜单样式（边框 + 下拉箭头），并加“译为”标签和“选择译文语言”提示。

## 已清理

- 未发布 GitHub Release，未回复 Issue。

## 交给用户验证

1. 在系统设置 → 隐私与安全性 → 录屏与系统录音中打开 `LibreShot`（会要求 Touch ID/密码；若提示“退出并重新打开”，照做）。
2. 从 `/Applications/LibreShot.app` 启动，`⌘⇧X` 或菜单栏剪刀打开遮罩。
3. 框选一段英文内容 → 点工具栏 `A` 气泡（原图翻译）。
4. 检查：`译为` + 语言菜单是否可见可点；等待“翻译完成…”，选区是否出现中文；再点翻译图标是否关闭翻译并回到原图。
5. 如需安装验收，重启前后各保存一张截图，把路径告知维护者补记录。
