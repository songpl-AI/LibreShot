# 贴图与滚轮统一需求：源码实现与回归

日期：2026-10-12。范围见 [统一方案](../design/pin-and-wheel-unified-plan-20261012.md)。本轮完成 #32、#33、#34 和 #22 的相关滚轮需求，保留前一轮 #35 定位修复与默认 ⌘P。未构建安装包、替换本机应用、发布或回复 Issue。

## 最终行为

- 普通滚轮与 ⌘＋滚轮缩放；Control＋滚轮只改显示透明度。透明度 10%–100%，普通滚轮每档 5%，精细滚动累积，惯性不继续改值；右键预设与滚轮共用每张贴图的状态。未定义修饰键组合不调整。文字输入控件不触发图像滚轮／捏合，复制／保存不烘焙显示透明度或缩放比例。
- 工具栏设置支持左／居中／右，旧配置默认居中，恢复工具栏默认值也恢复居中。从下一次截图／开始贴图编辑生效。按主工具栏边缘对齐，附属属性区更宽时仍使用主栏作为锚点；整体边界避让，绘制与点击排除范围共用布局。
- 属性滑块悬停显示当前值和滚轮提示，增加轻微边缘反馈；滚轮按硬范围调整，保留标签、精确输入与原有范围。一段连续滚动形成一条撤销记录，不同控件拥有独立分组标识，旧控件的延迟结束不会拆散新控件的分组；精确输入、系统取色器和工具／对象切换正确结束或阻止滚动。
- 普通贴图右键“编辑标注”原地编辑，邻接面板展示工具、属性、应用／取消、复制／保存，图像不被工具栏挤走。编辑时暂停背景拖窗、双击关闭和截图双击完成，保留文字／序号编辑与输入保护；⌘S／⌘⇧S 可保存编辑中的图像。
- 新区域贴图与文档贴图保留裁剪底图及局部标注对象；已有形状、文字、序号、马赛克／模糊可再次修改。仅保留裁剪区域，不持有整屏截图；序号从已有最大值继续。位图来源可添加新标注，但不声称可恢复其旧像素为独立对象。
- 应用更新同一贴图，保留位置、显示大小和透明度；取消不改变已提交内容。重复编辑始终从原底图合成，不反复烘焙效果。关闭清理面板、订阅、视图和编辑模型。长截图预览保持原适屏与编辑入口，未接入普通贴图滚轮。
