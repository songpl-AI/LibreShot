```bash
xcodebuild archive \
  -project LibreShot/LibreShot.xcodeproj -scheme LibreShot \
  -configuration Release -destination 'generic/platform=macOS' \
  -archivePath <fresh-output>/LibreShot.xcarchive \
  -derivedDataPath <fresh-output>/DerivedData \
  CODE_SIGN_IDENTITY=- CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= \
  PRODUCT_NAME=LibreShot PRODUCT_BUNDLE_IDENTIFIER=com.allensong.LibreShot \
  INFOPLIST_KEY_CFBundleDisplayName=LibreShot \
  MARKETING_VERSION=1.3.0 CURRENT_PROJECT_VERSION=8 \
  'ARCHS=arm64 x86_64' ONLY_ACTIVE_ARCH=NO
```

正式名称不等于公开发行签名：现有开发证书已过期，本包使用 ad-hoc 本地签名，保留 sandbox / hardened runtime，没有公证。不创建证书、不禁用系统安全检查、不重置权限。
