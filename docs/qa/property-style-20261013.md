# 属性栏视觉精简与取消收起入口

2026-10-13，源码基线 `f6fb622`。维护者要求缩小属性控件，并明确选择取消收起/展开。此次完成源码修改和生产视图渲染检查，尚未构建分发包或替换本机 1.3.20 build 48。

## 调整

- 常用单行属性栏高度由 32 点减为 26 点；矩形栏宽度由 454 点减为 385 点。降低阴影，缩小圆角、内边距与数值输入框。
- 预设色块改为 14 点圆形，按钮命中区域保留 22 点；自定义颜色采用同尺寸原生 NSColorWell 子类绘制圆点，保留原生选色面板、颜色绑定和辅助功能。原 `.minimal` 取色器即使指定小尺寸仍会画出偏大圆块，这是视觉不协调的主要原因。
- 样式、应用方式及颜色对象分段选择器使用 mini 控件；详细颜色区同步缩小，保留精确输入、独立颜色、恢复默认及撤销。
- 移除属性栏的收起箭头、“展开属性”条和对应临时状态。属性栏跟随当前工具/选中标注；选择模式且未选中标注时不显示，不增加悬停消失或额外显示入口。贴图主工具栏收起功能不属于属性栏收起，保留。

## 检查

- 工具属性检查通过：精确输入、Return/Esc、分组撤销、持久化、窄屏换行、独立序号颜色及导出像素。原生控件检查确认自定义色块实际尺寸 14×14，仍可激活原生颜色面板。
- 原生贴图回归通过：原位编辑、移动、首次点击、保存、撤销及工具栏定位。该检查在最后自定义色块绘制调整之前通过；最后调整由上述原生控件检查与渲染验证覆盖。
- 使用生产 SwiftUI 视图渲染 200/400/640 点宽度及浅/深色样例；已查看矩形、马赛克、序号详细颜色布局。证据在 `dist/property-style-20261013/`，最终日志为 `checks-final.log`、`build-final.log`，贴图日志为 `pinned.log`。

渲染样例为生产视图的独立测试截图，不是新包安装验收。本机换包需另执行安装与授权规范、同包重启前后真实截图保存。

## 常用拖动范围进一步调整

维护者反馈原滑条上限过大，常用小值挤在左端。滑条改为线性常用范围，原完整支持范围保留给精确输入及滚轮单级微调：

| 属性 | 滑条拖动 | 精确输入/滚轮 |
| --- | --- | --- |
| 粗细 | 1–10 | 1–20 |
| 圆角 | 0–30 | 0–128 |
| 字号 | 12–48 | 8–128 |
| 效果笔刷 | 12–60 | 12–120 |
| 马赛克颗粒 | 4–40 | 4–64 |
| 模糊强度 | 2–20 | 2–32 |

刻度按常用范围重新布置；滑条使用 mini 外观，属性间距由 4 点减到 3 点，内边距减到 2 点，保留滑条长度和数值输入。超出常用范围的已有值不会因显示属性栏被改写，滑块在端点显示，数值框保留真实值；悬浮提示显示当前值和常用拖动范围。

最终检查日志 `dist/property-style-20261013/range-checks-final.log` 通过，包括原生控件显示线宽 18 时不被常用上限 10 截断、精确输入仍能设为 19。最终生产视图渲染在 `common-ranges/`，已查看矩形常用值布局。此调整未换本机包。
