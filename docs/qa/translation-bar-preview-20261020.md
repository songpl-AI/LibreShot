## 改动

- `InlineImageTranslationView` 改为与属性条同款的紧凑条：目标语言、原文/译文、重译、校正、状态行；去掉独立面板的 78pt 预留和 ❌。
- 翻译会话存在时，属性条位置显示翻译条；不再和标注属性条叠成两块。
- 翻译完成后不再自动收起面板；条一直保留，直到用户关闭翻译。
- 再点工具栏“翻译”图标 = 关闭翻译并保留原图（原来只是切换面板显隐）。
- 工具提示改为“点击关闭翻译，保留原图；点选区可切换原文/译文”。

## 自测

- `xcodebuild Release`：BUILD SUCCEEDED。
- Preview 实际打开遮罩、框选设置窗口文字后点击“翻译”：出现翻译条；状态显示“排版完成”；条宽 360pt，位于工具栏下方。
- 再次点击“翻译”：翻译条消失，画布回到原图。

## 未覆盖 / 已知行为

- 未验证译文导出像素、保存/复制、其他目标语言、识别失败与复杂背景分支。
- 没有在 Intel、macOS 13–15 上运行；翻译本身要求 macOS 26+。
- 翻译进行中若选择绘图工具，仍显示翻译条而不是该工具属性；需要时可再调整为“有选中工具时优先工具属性”。
