# Issue #29：紧凑属性栏源码验证

日期：2026-10-11。基线：`498c51b`（1.3.15 发布记录）。维护者批准采用“短滑块＋可编辑当前值”的第三种方案。本轮修改源码和使用文档；未构建发行包、替换本机应用、更新权限、发布或回复 Issue。

## 实现范围

- 粗细、圆角、字号、笔刷、马赛克颗粒和模糊强度改为短滑块与精确输入；保留原数据模型支持的完整范围。拖动按整数调整，精确输入支持范围内小数；常用刻度只作定位提示，不限制到预设档位。
- 常用工具宽屏可单行显示，高度 44 点；窄屏按控件宽度分行。属性布局计算同时供截图窗口定位和命中排除使用。收起后保留带工具名称的展开入口，每个截图会话初始展开。
- 快捷色板提供四种颜色，固定尺寸原生色井保留自定义颜色；序号默认展示样式、填充／描边快捷色和字号，额外展开独立边框／填充／数字颜色，保留自动数字配色及无边框。
- 调整中实时预览，松手或切换工具时保存最终参数；已有标注的整次滑动登记为一次撤销。返回初值的滑动不新增撤销，也不覆盖既有下次使用偏好。
- 数值输入回车确认，Esc 放弃草稿；空值／非有限数值不应用，超出范围限制到合法值。单纯聚焦不会把已有小数强制改成展示的舍入值；旧对象草稿不会写到新选中的对象。
- 恢复默认、工具独立记忆、既有标注编辑、文字／序号缩放和导出行为保留。自定义取色控件销毁时解除活跃色井。

## 验证

- `bash tests/run-tool-properties-checks.sh`：通过。新增滑动预览／最终值持久化／单步撤销／无变化与切换工具收尾；精确输入校验；所有工具在 200／400／640 宽度的控件布局；原生 SwiftUI 数值输入框的回车、Esc 和无效输入隔离。既有迁移、圆角与序号颜色持久化、恢复默认及生产导出像素检查通过。
- `bash tests/run-toolbar-checks.sh`、`bash tests/run-issue25-checks.sh`、`bash tests/run-number-tool-checks.sh`：通过。覆盖工具栏边缘定位、保存链路、空白双击完成／文字序号编辑及缩放回归。
- `git diff --check`：通过。
- 使用 `LIBRESHOT_PROPERTY_QA_OUTPUT` 渲染实际 `ToolPropertyBarView`，检查所有工具的宽／窄布局、展开详细颜色、收起状态和深色模式。发现系统 SwiftUI 取色控件固有宽度挤压标签，改用固定尺寸原生 minimal 色井后复查；详细颜色对象选择器隐藏重复标签，避免窄屏截断。
