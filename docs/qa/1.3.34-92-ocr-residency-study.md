# 译图关窗驻留追踪与 OCR 传输修复

2026-11-22。主指标为关窗后第 55–60 秒主进程 physical footprint 的中位数。沿用 build 91 的 3024 × 1964 Retina 环境、2048 × 1280 公开选区和英译简中设置。测量完成后采集 VM 地图及堆，开启分配栈记录的轮次仅用于归因。

## build 91 复现

| 场景 | 关窗一分钟 |
| --- | ---: |
| 新进程普通复制一次 | 39.2 MiB |
| 新进程译图复制一次，8 轮 | 55.9–76.1 MiB |
| 新进程译图后直接关闭，两轮 | 86.1、86.2 MiB |
| 同一进程普通复制六次 | 42.8 MiB |
| 同一进程译图后直接关闭六次 | 75.4 MiB |
| 同一进程译图复制六次，两轮 | 127.4、96.7 MiB |

当前独立进程译图复制未重现历史单轮 90.8 MiB。连续六次的首轮压力复现在第二次由约 95 MiB 抬至约 128 MiB，后四次短间隔读数近似持平。两轮连续译图复制的一分钟快照均保留两组约 14.8 + 10.0 MiB 的脏页或已压缩页。独立进程 55.9 MiB 的快照中少了约 14.8 MiB 映射，71 MiB 左右的轮次同时具有 14.8 和 10.0 MiB 映射。关键模型的直接堆类型未出现在采集到的关窗快照。

只译图和译图复制的 malloc stack 记录均归因了一组约 14.8 MiB 的 VM 分配，来源为 `OCRWire.write` 的 CFData 转 Swift Data。复制轮的另两笔约 10 MiB 分配分别落在 SwiftUI 预览准备、导出圆角绘制。仅凭 VM 地图无法确定每个当前活对象的所有者，当前结论依据地址对应的分配栈。

## build 92 修改

提交 `8987065`。在同步写 OCR 任务文件期间保留 CFData 所有者，并通过无拷贝 Data 读取已有像素。保持传输格式、长度校验、色彩元数据和工作进程协议。

- 固定的 2048 × 1280 原生 P3 裁剪输入，两个版本写出的 15,478,976 个 raster 字节、解码元数据、Vision 文本和位置一致。保留原始像素缓冲避免复用时，三对离屏进程的写入新增峰值中位数为 **14.86 → 0.09 MiB**，隔离进程内核累计峰值中位数为 **64.80 → 50.05 MiB**。实机一分钟占用另测。
- 使用真实 OCR helper 的集成套件通过。覆盖中文、英文、裁剪最后一行填充、透明 sRGB/P3、取消与排队、异常结果和父进程异常退出。

证据位于与工作树并列的 `LibreShot-memory-evidence/residency-91/`。保留逐点采样、VM 快照、分配栈、像素输出和复测脚本。跨轮公开素材图有顶部小区域和译文标点变体，文件保留并记录差异。每一次复制的 PNG、TIFF 与 AppKit 读取均单轮逐像素校验。

## 两版固定安装路径实测

单位为 MiB，主进程关窗第 55–60 秒的采样中位数。连续场景每版用两个独立新进程，各在同一进程中做六次译图复制。独立场景每轮从新进程开始。两个版本依次测量，使用的自然图像变体与逐次值见归档。

| 场景 | build 91 | build 92 |
| --- | ---: | ---: |
| 同一进程译图复制六次 | 96.7、127.4（中位 112.0） | 60.0、94.6（中位 77.3） |
| 新进程译图复制一次 | 8 轮，中位 70.6，范围 55.9–76.1 | 3 轮，中位 55.7，范围 46.0–75.6 |
| 新进程只译图后关闭 | 86.1、86.2 | 45.2、61.1 |
| 新进程普通复制 | 39.2 | 36.6 |
| 新进程译图后保存 | 70.2、72.8 | 75.4 |

连续译图复制的一分钟中位数本次下降 34.7 MiB（31.0%），全程内核累计峰值的两组中位数由 197.0 降至 173.2 MiB。新版仍有一组关窗后达 94.6 MiB。保存场景目前只获得一次新版读数，现有证据不足以确认该路径的待机变化趋势。自然采样仍按场景与启动条件保留，所有数值都是该次运行观察值。

连续场景 24 次实际复制均验证 PNG、TIFF 和 AppKit 读取逐像素一致。两个版本都得到同两种公开素材像素指纹。新安装包的实际译图采样记录到了 OCR 辅助进程。两份 build 92 连续复制的关窗 VM 快照都未显示 build 91 两份快照中的两块 14.8 MiB 分配，目前的关窗波动伴随其他区域变化。原始数据和复算入口为证据目录的 `installed-comparison-91-92.json` 与 `tools/compare-installed-residency.py`。

另对 build 92 的真实译图复制开启分配栈记录。快照及地址查询中的三份大块均约 10 MiB，其中可见 SwiftUI 图像准备与圆角绘制栈，未再看到原先约 14.8 MiB 的 OCRWire CFData 桥接分配。这轮使用跟踪器的结果单列，完成后按普通配置重启相同的签名包。
