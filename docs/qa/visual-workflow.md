# 原位翻译与编辑器布局验收

日期：2026-09-23。本轮根据用户提供的两张参考图改动截图编辑流程；不修改录屏权限，不覆盖 `/Applications/LibreShot.app`。

## 行为

- 截图工具栏的翻译按钮直接作用于冻结的原选区。译文覆盖在原图文字区域，原文/译文切换不移动图片，不再跳入独立的图文列表窗口。
- 保留选区内已有标注；校正译文放入按需打开的弹窗。翻译未完成或文字溢出时禁用导出；复制、保存、贴图、OCR 使用当前显示的图像底图。
- 移动或调整选区会移除旧翻译，重新启动时产生独立会话 ID。关闭、取消及重试继续使用已有任务取消和过期结果隔离机制。
- 译文采样原文字的主要颜色，按字形实际范围适配单行高度，避免中日韩字体行高导致过度缩小。复杂背景与过长译文仍保留校正提示。
- 工具栏为 42 pt 高单排，按钮 30 pt；自定义顺序决定主栏的显示优先级，放不下的已启用工具按原顺序进入更多菜单。完成和取消始终显示；未自定义排序时翻译和样式优先保留。全部工具放得下时隐藏更多菜单。使用原生材质、克制的选中态和系统图标。
- 长图编辑器默认按宽度适配，提供全图、100%、手动缩放和触控板缩放。滚动区域按实际原生视口计算，窗口变化后重新适配，避免因滚动条宽度出现额外水平滚动。
- 小图居中、不自动放大；长图从顶部显示。标注使用原始图片点坐标，缩放与滚动不改变导出的物理分辨率。

## 限制与后续实机验收

- 本轮不承诺逐字还原原字体、字重、混合彩色片段或复杂背景；按 OCR 原始文字行翻译，跨行段落的连贯性仍有限。
- 缺少语言包时的系统下载弹窗、多显示器、旧版 macOS、Intel 运行时和真实 Finder 长截图仍需实机复测。双架构编译不等于双架构运行验收。
