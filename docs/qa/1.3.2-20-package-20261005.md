## 本次归档修复与复验

原流程实际 `xcodebuild archive` 在 OCR helper 编译缓存创建处失败，退出 65；Xcode 生成的脚本沙盒只给予 DERIVED_FILE_DIR 下声明目录本身的访问，并未允许其子文件。目录尾部加斜杠的实验仍失败，已撤回。

将缓存移入 Xcode 允许递归写入的 `TEMP_DIR` 后，编译通过，进一步暴露 lipo 在应用包输出旁创建 `.lipo` 临时文件也被拒绝。最终在 TEMP_DIR 完成编译、架构合并及 helper 签名，仅将完成的可执行文件复制到声明的输出路径。保留 `ENABLE_USER_SCRIPT_SANDBOXING = YES`，未放宽应用权限。

反馈回路使用真实发行归档，不使用无法覆盖 Xcode 沙盒规则的模拟单元测试。原失败命令复验退出 0，随后从新产物目录完整执行：

```bash
bash build_release.sh --ad-hoc "$PWD/dist/LibreShot-1.3.2-20-github-candidate-r2"
```

完整脚本退出 0。已有的 Swift actor/无异步 await、图标尺寸与 App Category 编译警告仍存在；本轮没有将它们视为已修复。
