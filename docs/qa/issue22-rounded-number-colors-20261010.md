# Issue #22：矩形圆角与序号独立颜色（源码验收）

日期：2026-10-10。本轮不增加属性栏显示／隐藏开关，沿用选择工具或已有对象时自动展示的交互。

## 已实现

- 矩形圆角选项 0／4／8／16／24／32，默认直角。缩小矩形时，实际半径约束到短边的一半；预览、导出及边框命中共用圆角路径。
- 序号边框、填充、数字独立颜色，共用一排色板与自定义颜色入口；描边模式隐藏填充项，切换模式保留填充偏好。实心序号支持无边框，数字支持自动配色，自动黑白数字依据实际填充颜色判断。
- 新参数独立保存到工具偏好，创建新对象时带入；选中已有对象显示其实际参数，修改与恢复默认可撤销。撤销只恢复画布，明确设置的下次使用偏好保持原规则。
- 新持久化字段为可选值，旧设置及旧对象继续使用直角、原主颜色和原序号自动配色，不覆盖原截图目录、快捷键或工具顺序。
- 属性栏保留清晰的分行标签，通过颜色对象切换避免铺开三套色板。窄宽度沿用横向滚动，组合工具栏继续参与屏幕边缘定位及双击排除。
