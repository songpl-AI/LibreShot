日期：2026-10-10（Asia/Shanghai）。状态：源码回归、固定包安装与同包重启前后区域截图验收通过；实体 Option 与外接屏全屏捕获通过；Mac 全屏标注与保存通过，Mac 全屏剪贴板和外接屏完整导出待补；准备发布原包。

## 原因与修复

build 34 的全屏入口未指定显示器 ID，抓图服务回退到 ScreenCaptureKit 列表第一块屏幕，忽略鼠标。修复为入口同步读取鼠标在 AppKit 全局坐标中的位置，对照 NSScreen.frame 选择显示器 ID，随后才开始异步抓图；鼠标位于显示器间隙时回退到系统主屏。显式 ID 不会被后续鼠标或焦点移动改变。标注窗口按目标屏幕可用区域定尺寸并居中，其他图片编辑入口保持原行为。

## 回归检查

`bash tests/run-fullscreen-checks.sh` 使用实际 AppDelegate 的注入 seam，只替换屏幕位置和图片来源。修改前退出 1：`FAIL: full-screen capture ignored display at trigger time; requested nil, expected 42`。修改后退出 0：触发时目标 ID 42 显式送到抓图入口，异步任务执行前变成 77 也不改截图目标；模拟左侧负坐标、上方、下方屏幕，间隙及空列表回退通过。目标屏幕的标注窗口居中检查通过。既有确认前无保存、标注导出、Enter 保存与剪贴板一致、Esc 取消、关闭自动保存后双击仅复制均通过。
