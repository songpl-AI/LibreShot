# 马赛克与模糊：连续预览和两种应用方式

日期：2026-10-05。已打包并安装 1.3.6 build 26；安装与授权验收见 [build 26 验收记录](1.3.6-26-package-20261005.md)。

## 复现与根因

用户反馈连续拖动时效果直到松手才出现，要求马赛克和模糊均支持涂抹、框选。生产绘制入口已经在拖动时更新 currentAnnotation，但原调度每次取消 24ms 延迟任务，并使在途结果版本过期。持续输入间隔小于 24ms 时，任务反复取消或结果丢弃，显示要等输入停止。

回归入口为 `bash tests/run-effect-checks.sh`。修复前以生产 startDrawing/updateDrawing 连续发送 60 次、每次间隔约 10ms，不调用 endDrawing，确定触发 `continuous drag must show effect before pointer-up` 失败；日志 /tmp/libreshot-live-effects-before.log。修复后相同检查通过。

## 行为

- 两种工具的效果参数面板均增加“涂抹 / 框选”分段选择。初始方式保持马赛克框选、模糊涂抹；截图会话内分别记住各工具的方式，不新增跨启动设置。
- 模式切换用于下一笔绘制，取消当前标注选择并激活该效果工具，不擅自把现有笔迹变成矩形。涂抹时显示笔刷大小，马赛克另显示颗粒大小，模糊另显示强度。
- 涂抹按实际路径生成圆头掩膜，两种算法均只作用在笔迹上；框选按矩形掩膜处理。效果预览和最终导出共用渲染器。
- 预览每次只运行一个后台任务，保留一个最新请求。连续输入合并请求而不取消每一帧，已完成的同源画面可持续发布；上一帧完成后处理最新位置。源图/裁剪改变或会话关闭时使旧结果失效。
- 两种涂抹效果选框包含整条路径，只在可见笔迹附近命中；矩形效果可选中、移动及八向缩放。微小点按仍沿用防误触阈值。

## 2026-10-06：连续补涂交互修复（尚未安装）

build 26 用户反馈涂抹松手后自动选中笔迹，出现选框，必须先取消选择才能补涂。新增生产手势回归在修复前明确失败：`effect brush must stay unselected after pointer-up`，日志 `/tmp/libreshot-repeat-brush-before.log`。

根因是 `endDrawing` 对所有绘制结果自动选中，同时绘图模式中的轻点可自动选中旧笔迹。现在马赛克/模糊涂抹提交后不选中，涂抹模式也不抢占轻点去选择旧笔迹，直接继续下一笔；框选仍自动选中。需要编辑旧涂抹时主动切换“选择/移动”。绘制阈值、效果参数、导出与逐笔撤销保留。

效果检查 11 组通过，包括重叠补涂、轻点不选中、首笔未移动、主动选择、撤销和框选选中；工具栏检查 26 组通过。日志 `/tmp/libreshot-repeat-brush-after.log`、`/tmp/libreshot-repeat-brush-toolbar.log`。检查编译包含生产视图。无临时调试日志。
