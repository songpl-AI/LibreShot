## 本次改动

- 画布拖拽时不再只映射到起始行；指针进入另一行后按阅读顺序构建范围：起始行尾段、中间行整行、结束行首段。
- 反向从下往上拖也选中同一段文字。
- 单行内拖选、单击整行、双击整行复制、全选、未选中复制全部、`Return` 均保持。
- 高亮仍按字符范围绘制；中间整行显示整行选中框。

## 交给用户验证

1. 在一段多行文字上，从第一行中间拖到第二行中间：起始行只选后半段，结束行只选前半段，中间行整行选中。
2. 从下往上反向拖：应选中同一段文字。
3. 拖过三行以上：中间行整行高亮，复制内容带换行。
4. 再试单击整行、双击复制整行、全选、不选直接 `⌘C`，确认没有回归。
5. 如果跨栏/表格时选中了不需要的中间行，告诉我具体布局，我再加阅读顺序约束。
