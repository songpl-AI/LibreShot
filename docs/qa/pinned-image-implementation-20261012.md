# 贴图位置、默认快捷键与滚轮缩放：源码实现

日期：2026-10-12。方案见 [前置评估](pinned-image-assessment-20261011.md)。本轮完成源码和回归检查，未构建新试用包、替换本机应用、恢复授权或发布。

## 最终行为

1. 区域截图的最终全局选区矩形随出图结果传到贴图窗口。普通区域贴图创建时采用截图原位置与逻辑点尺寸，不先居中，不强制 360×280 初始下限，也不强制缩至可见区域的 80%。在像素密度不同的屏幕上使用逻辑尺寸，避免 Retina 像素尺寸误作窗口尺寸。
2. 不存在有效源选区时，普通贴图在当前文档屏幕适屏显示；源屏幕完全不可达时回退可用屏幕。长截图预览保留原适屏居中策略与界面。
3. 新用户和主动恢复编辑快捷键时，默认 ⌘P 直接将当前截图选区／标注贴图。已有自定义、主动清除和旧快捷键配置保留，不强制补键。设置与工具栏提示说明入口。当前仍保持文字／属性输入及重复按键保护，不新增全局快捷键或最近截图缓存。
4. 普通贴图接收本窗口的滚轮和触控板捏合，按原图比例调整窗口；鼠标位置为缩放锚点。拖边仍可调整并保持比例，下一次滚动读取实际窗口尺寸，不跳回旧比例。右键可“恢复原始大小”。
5. 普通滚轮按分档变化，精细滚动使用小幅连续变化，限制单次增量，忽略滚动惯性。通常缩放范围为原图 10%–800%；极长图片的初始适屏比例小于 10% 时，允许以该初始比例为下限，不因首次滚动突然跳到 10%。设置窗口前对齐屏幕像素网格，避免浮点值被 AppKit 向上取整产生额外像素与锚点漂移。
6. 缩放只影响显示，原 NSImage 和图像数据不变。拖动、双击关闭、右键复制／保存和透明度保留。长截图预览不接入本轮缩放事件，不使用全局事件监听或新增权限。

## 修改位置

- `LibreShotApp.swift`：区域结果携带原选区位置；图片编辑器贴图回退到文档当前屏幕。
- `PinnedImageWindowController.swift`：区分普通贴图与长截图预览的初始布局；控制原生窗口尺寸、像素对齐与鼠标锚点；通过 hosting view 接收本窗口事件；右键恢复原始大小。
- `EditorShortcuts.swift`：补默认 ⌘P；继续沿用既有设置保存和冲突处理。
- `EditorToolbarView.swift`、`SettingsView.swift`：补操作说明和默认键提示。
