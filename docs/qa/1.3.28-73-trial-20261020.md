## 交给用户验证

1. 框选后画矩形：默认属性栏应只有 3 个预设色、吸管、粗细滑块、圆角滑块和 `⋯`，不再永久显示标题/数值。
2. 悬停滑块：显示当前值、常用范围和滚轮提示；拖动时实时预览，松手后一次撤销恢复。
3. 点 `⋯`：切换为完整属性栏，显示调色盘、精确数值、恢复默认；点右侧 `⌃` 或按 Esc 收起，不应取消截图。
4. 点吸管：出现“点击截图取色 · Esc 取消”提示和十字光标；点截图后颜色应用到当前工具（序号为当前填充/边框），再点吸管或 Esc 取消。
5. 文字/序号/马赛克/模糊分别检查默认行与完整属性；贴图和长图编辑器的属性栏也应一致。
6. 完成截图并保存；正常退出并重启同一应用，再次截图保存，确认屏幕权限与保存目录可复用。
