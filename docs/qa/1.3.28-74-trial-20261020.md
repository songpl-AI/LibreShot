## build 74 的处理

- 属性栏恢复为原来的单行完整布局，包含预设色、调色盘、滑块、精确数值、恢复默认和序号独立颜色。

- 取色期间抑制空白双击完成；Esc 取消；选预设色也会退出吸管。
