# LibreShot 1.2.0 标注验收

日期：2026-09-13。环境：Apple Silicon，macOS 26.5.2。发布构建 7，沿用已验收的本地试用包。

## 自动回归

运行 `tests/run-toolbar-checks.sh`，退出码 0。

- 64 组当前工具与已有标注组合：点击选中、不新增标注，选中对象可移动。
- 从已有标注起点直接绘制、首次回调已有位移、拖出后回到原点仍算拖动。
- 空心矩形/椭圆、箭头及折线路径的实际笔画命中；上层空心图形不挡住内部文字。
- 重叠处上层优先，文字选中同步字号，双击继续编辑，输入中的文字不被误取消。
- 矩形和椭圆共 16 组缩放控制点；缩到最小尺寸、控制点距离选择、选中形状内部移动及绝对位移。
- 形状内部其他标注可选中；正在移动截图范围时不会改为移动标注；蓝白控制点重叠时白色优先。
- 原有 72 组选区缩放、144 种工具栏布局、一次 Esc、保存失败保留剪贴板及所有完成入口回归通过。
- 系统 Vision OCR、同语言翻译和翻译状态回归通过。本次检查未检测到英译中模型，跨语言输出为 `NOT RUN`；本次未修改翻译实现。

## 原生界面实测

使用 `tests/AnnotationSelectionUITestApp.swift`，复用生产 `OverlayView` 和 `OverlayViewModel`，用独立设置域及合成截图内容验收。

1. 箭头工具启用时单击红色矩形边框：切换选择模式，标注数量仍为 2，出现八个蓝色控制点。
2. 从选中矩形内部拖动：矩形移动，内部蓝色文字不动，外层白色截图范围不动。
3. 拖动右下角蓝点放大，再拖动左上角蓝点缩小：边界和控制点同步变化，截图范围不动。
4. 切回箭头工具，从矩形边框直接拖动：新增箭头，数量变为 3，矩形位置和大小不变。
5. 箭头工具启用时单击文字：自动选中文字；双击文字进入编辑，标注数量保持 3。

原生界面实测矩形；椭圆的八向缩放由生产模型自动回归覆盖。多帧长截图、Intel 实机和其他 macOS 版本不在本次验收范围。未测大量标注的延迟或前后进程内存差值。
