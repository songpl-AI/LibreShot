## 本次改动

- 每行 OCR 文本按字符范围保存选择；拖动时用 Core Text 字距计算起止位置，高亮直接画在原文字上。
- 单击一行仍选中整行；双击复制整行；拖拽则选中任意字符/词句，底部显示“已选 N 字”。
- `⌘C`/`Return` 复制当前字符范围；没有选中时仍复制全文；`⌘A` 全选。
- 英文、数字、中文都按字符范围处理；当前阶段只支持在**同一行内**拖选，跨行选择下一步再做。
- 保留悬停高亮、图层/列表切换和底部固定操作条。

## 交给用户验证

1. 打开 OCR，在一行英文上拖过几个词：只高亮这几个词，底部显示“已选 N 字”，`⌘C` 复制这一段。
2. 在一行中文上拖过几个字：高亮范围应贴合文字，不整行变蓝。
3. 单击一行仍整行选中；双击该行直接复制整行；不选任何行时 `⌘C` 复制全文。
4. 切到“列表”确认全文/翻译入口仍在。
5. 如果高亮和原文有轻微字距偏差，告诉我具体是中/英文、字号大还是小，我按真实截图继续调。
