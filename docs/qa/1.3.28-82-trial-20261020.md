- `OCRResultView` 改为绑定 `String`，列表编辑器可输入/删除/撤销；保留 `OCRResultView(text:)` 初始化给旧窗口和测试。
- `OCRTextLayerModel` 增加 `listText`；编辑值在图层/列表切换间保留。
- 列表内“复制文本”“翻译”使用编辑后的文字；编辑只影响列表，不回写图层区域。
- 编辑后出现“恢复原文”；顶部提示“编辑仅影响此处的复制/翻译”。
- 列表编辑器的 `⌘C` 恢复为复制选中的文字（不再被“复制全部”快捷键抢占）；按钮仍复制全部文本。

## 交给用户验证

1. 打开 OCR，切到“列表”，改一个错字：字符数应变化，“复制文本”粘贴出来是修改后的内容。
2. 选中一段文字按 `⌘C`：应复制选中的一段，而不是整篇。
3. 点“恢复原文”：应还原 OCR 原始文字。
4. 切回“图层”拖选：仍按原图 OCR 原文复制；这是预期行为，列表编辑只影响列表。
5. 编辑后点“翻译”：应翻译修改后的文字。
