## 原因与修复

- `OCRTextLayerCanvasView` 只被动重绘；`selectAll()` 改了模型和底部计数，但没有观察 `objectWillChange`，SwiftUI 的 `updateNSView` 也不保证在引用对象内部状态变化时重绘。
- 让画布观察 `OCRTextLayerModel`，并在模型变化后异步 `needsDisplay = true`；同时把画布标记为 `@ObservedObject`，双保险。
- 新增“已全选 N 行”状态，避免只有“已选 N 行”时看不出全选完成。
- 回归测试直接渲染窗口并比较全选前后的蓝色像素，确保不是只改文字。
