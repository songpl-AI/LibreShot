# 默认工具与序号编辑：实现及验证

日期：2026-10-05。基于 master 2d4e04c，在 codex/default-tool-number-editing 实现。功能实现时尚未发布；现已构建并安装本地 1.3.5 build 24，基础验收通过，见 [安装记录](1.3.5-24-package-20261005.md)。仍未公开发布。

## 实现范围

1. 工具栏设置新增默认工具选择，允许选择/移动及已显示的标注工具；保存、翻译等执行动作不可设为默认。出厂默认仍为选择/移动，隐藏默认项或加载无效值回退选择模式。普通截图与图片编辑器（包括长截图结果）统一初始化。
2. 双击序号进入内联编号输入，首次选中全部内容，支持 1–9999；回车提交，Esc 取消本次改号。数字输入不会触发工具快捷键，退出输入后恢复快捷键。改为 N 后下一序号为 N+1，可手动从 1 开始另一组。换颜色不自动重置编号。删除最近创建/明确改号的序号回退下一编号；删除中间项不重排其他内容。无效输入不能直接导出。
3. 序号右下角手柄缩放，字号限制 8–96，中心保持不变；后续序号继承大小和颜色。多位数扩大圆形轮廓，实时预览、命中、选框及导出共享几何；字号独立于普通文字。放置、改号、删除和序号缩放支持撤销，恢复相应计数/样式状态。

普通文字保持一次 Esc 取消截图的原行为；序号输入时 Esc 的局部取消是本功能的特例。数字 9999 后自动放置到达上限，需要将已有序号改为较小值后继续。

自动翻译、局部滚动提示、保留固定区域并补白均未实现。
