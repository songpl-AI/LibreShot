# 自定义颜色入口辨识

2026-10-13，基线 `be77855`。维护者批准将第四个颜色入口改为容易识别的图标。

- 原生 NSColorWell 改为绘制单色调色盘图标，下方细色条指示当前自定义颜色；与红绿蓝快捷色圆点区分。
- 控件实际点击区域由 14×14 扩大为 22×22，与快捷色按钮一致；整组宽度保持原测量值。
- 保留原生颜色面板、颜色绑定、独立序号颜色及辅助功能标签；悬浮提示明确“打开调色板选择更多颜色”。
- 工具属性回归和原生颜色面板激活检查通过，含精确输入、大值不截断、撤销、持久化及导出像素。浅/深色和窄宽布局使用生产 SwiftUI 视图渲染；已查看矩形预览。日志及图片在 `dist/custom-color-icon-20261013/`。

本次为源码修改，尚未构建新包或替换已安装的 1.3.21 build 49。新包安装验收不能由此渲染/回归结果替代。

## 安装实测发现与修复

build 50 点击调色盘可创建 Colors 窗口，但它被 `.screenSaver` 层级的截图遮罩挡住。为原生属性回归窗口设置生产层级，并断言面板在其上方：旧实现实际失败（`Color panel appears above the production screenshot overlay`）。激活颜色控件时把面板提高到所属窗口上方，取消激活恢复原层级；同一检查及整套属性回归通过。最终候选改为 1.3.22 build 51，build 50 不交付验收。
