# 只有约 1.9 MB，这款免费 Mac 截图工具又变好用了

之前和大家分享过我做的 Mac 截图工具 LibreShot。

这段时间，我根据自己的使用感受和大家的反馈，继续做了一轮更新。目标很简单：让截图之后的那些小操作，更顺手一点。

比如，截完图想标个重点，写错了想改一下，发给别人之前想遮住姓名和账号，或者把一整页内容保存下来。

现在，这些事情用 LibreShot 就能完成。

【图 1：一张完成后的示例截图，展示箭头、文字和 1/2/3 序号；不要塞入全部工具。】

## 小巧、免费，内容在本机处理

先说三个我很看重的特点。

**安装包小。** 当前版本的安装包约 1.9 MB，下载和保存都很方便。这里说的是安装包大小，不是运行时占用的内存。

**免费使用。** 项目免费开源，不需要注册账号，下载后就可以开始使用。

**内容在本机处理。** 截图、标注和图片中的文字识别，不需要把内容上传到网上。断开网络，也能完成这些日常操作。

如果你经常处理工作资料、聊天记录，或者含有个人信息的截图，这一点会比较实用。

翻译也可以离线使用，不过第一次需要联网下载所需的语言包。打开下载页面、查看更新同样需要网络。

【图 2：当前 Release 的下载附件，突出“LibreShot-1.3.9-31.dmg”及约 1.9 MB；隐藏无关浏览器信息。】

## 标错了，可以接着改

截图最常见的用途，就是“你看这里”。

LibreShot 可以画框、画箭头、写文字，也能放上 1、2、3 这样的序号，把步骤说明白。

这轮更新后，鼠标移到可以选中的标注上，会出现手型提示。需要调整时，选中再拖动；文字和序号也可以直接拖动到合适的位置。

文字写错了，可以双击修改。序号也能改数字、调大小和颜色，后面的编号接着往下排。下一次截图默认先进入“选择和移动”，也可以在设置里换成你常用的工具。

不用因为一个箭头放歪了，就重新截一张。

【图 3：短动图展示“移动文字 → 双击改字 → 调整序号”，约 6–10 秒，动作不要过快。】

## 发图之前，顺手把隐私遮一下

姓名、账号、手机号，或者不想公开的聊天内容，发图前都可以先处理。

马赛克和模糊现在都有两种用法：

- **涂抹**：像用画笔一样，划到哪里就处理哪里。松手后还能继续补涂。
- **框选**：拉出一个框，一次处理整片区域。

两种方式都能一边拖动、一边看到效果，再按需要调整大小或强度。

处理完后，记得检查一下结果。重要信息要遮到看不清，不能只追求效果好看。

【图 4：用虚构姓名、账号做示例；短动图展示连续两次涂抹，再展示一次框选，说明效果实时出现。】

## 一页放不下，就截成长图

网页、文档、长列表，有时候一张截图装不下。

选择长截图，框好要保存的区域，再慢慢向下滚动，就可以把内容接成一张长图。完成后，还能继续标重点、加说明，再复制或保存。

这轮也改善了滚动过程中短暂往回看的处理。不过，长截图仍建议保留足够的画面重叠，避免一下滚得太快；遇到复杂页面，完成后检查一下有没有漏内容。

【图 5：左边是普通窗口的一屏，右边是生成的长图；长图只展示上、中、下三个局部，避免整张缩到字都看不清。】

## 图里的文字，也能复制出来

碰到只能看、不能复制的文字，可以先截下来，再用文字识别提取，省去手动重打。

识别后的文字可以复制，也可以翻译。需要时，还能把译文放回图片原来的文字位置，方便对照阅读。

翻译需要 macOS 26 或更新版本，并先下载相应语言包。原图翻译更适合背景简单的文档和界面；识别或翻译之后，重要内容还是要核对一下。

【图 6：公开示例图中的中英文文字及识别结果。翻译可作为附图，不要让读者误以为所有 Mac 都支持。】

## 下载和第一次使用

LibreShot 目前适用于 macOS 13 及以上版本，支持 Apple 芯片和 Intel 芯片的 Mac。

从下面的 GitHub 页面下载 `.dmg` 安装包，打开后将 LibreShot 拖到“应用程序”里。

首次使用，需要在“系统设置 → 隐私与安全性”里允许它录制屏幕，这是截图所需的权限。开启双击 Option 截图时，还需要输入监控权限。

如果系统提示无法直接打开，请按下载页的安装说明处理。升级后若仍不能截图，也可以查看同一份授权说明。

**下载最新版本：** https://github.com/songpl-AI/LibreShot/releases/latest
