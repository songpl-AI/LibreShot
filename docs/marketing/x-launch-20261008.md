# LibreShot X 首帖草稿与演示方案

状态：文案草稿与演示第一版已完成，未发布。素材见 [x-demo-20261008/README.md](x-demo-20261008/README.md)。

## 宣传角度

主帖介绍免费开源的 Mac 截图工具，并邀请用户提出改进意见。视频用截图中的文字在原位置变成英文吸引注意，再展示一次简短截图标注，兼顾日常使用场景。
免费、开源、原生 macOS 是试用理由。滚动长截图、独立 OCR 流程和贴图可以用于后续独立帖子。
这只是传播策略判断，不保证播放量、转发或下载。

## 推荐英文主帖

I built LibreShot — a free, open-source screenshot app for Mac.

Capture, annotate, extract text, and translate it in place.

I'd love feedback from Mac users and developers. What would you improve?

https://github.com/songpl-AI/LibreShot

正式发布以 X 编辑器计数为准。翻译系统要求在视频字幕与第一条回复中明确。

## 第一条回复草稿

It also includes annotation, scrolling capture, OCR, and pinning screenshots on screen.

The app supports macOS 13+. Translation requires macOS 26+; download the language packs once, then translate offline.

Download & setup: https://github.com/songpl-AI/LibreShot/releases/latest

## 主演示：约 18 秒

| 时间 | 真实画面 | 英文字幕 |
| --- | --- | --- |
| 0–3 秒 | 同一截图的原图与真实译图切换，先展示结果 | Translate text inside screenshots. |
| 3–8 秒 | 对一张背景简单的中文说明卡片进行区域截图，画一个重点框 | Capture. Annotate. |
| 8–12 秒 | 切到另一段无标注截图的真实翻译操作：选择 English、显示实际翻译结果 | Translate in place. |
| 12–15 秒 | 原图/译图切换；再复制或保存 | Compare. Copy. Done. |
| 15–18 秒 | 保留完成后的截图，叠加名称与短句 | LibreShot · Free & open source |

翻译镜头保留小字：Translation: macOS 26+ · Language packs required。
原图/译图必须来自 LibreShot 实际操作。首段可复用后面的真实译图，不制作虚假的功能效果。
可以剪掉鼠标停顿、打开菜单前的空白时间；若明显压缩处理等待，注明“Wait shortened”。
优先简洁 MP4，1280×720、30 fps、无旁白，以字幕说明；实际 UI 字体须在手机缩略画面中可辨认。
无需刻意塞入箭头、矩形、文本、独立 OCR 复制和贴图操作。实测支持连贯流程后再选择是否加入贴图。

## 最省事的备选素材

如果连续录屏不顺利，取得 3 张真实产品画面：原图、译图、导出结果。
把真实画面剪成 10–12 秒短片，加局部放大与字幕。明确这是结果展示，不模拟点击，也不暗示连续实录。
也可以直接发布原图/译图两张静态对比图，先验证观众是否对这个功能感兴趣。

## 拍摄用原创中文内容

标题：周末出行清单

出发前确认车票和天气。
随身携带充电器和雨伞。
把酒店地址保存到手机。

使用白底、深色字、宽松行距。素材为自制测试卡片，可标注“Sample document”。
不要放真实账号、私人文件、聊天内容，也不采用表格、照片背景或密集小字作为首个演示。
译文必须使用应用实际结果，英文表达、覆盖位置及溢出情况都要检查后再用于宣传。
