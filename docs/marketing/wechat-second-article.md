# 只有约 1.9 MB，这款免费 Mac 截图工具又变好用了

之前分享过我用 AI 做的 Mac 截图工具 LibreShot。最开始，它只是一个给自己用的小工具：能截图、标注、识别文字，再把图片保存下来。

后来一边用，一边根据大家的反馈修改，我发现，截图工具好不好用，往往体现在一些小地方。

常用的按钮能不能放在前面？不用的工具能不能藏起来？开始截图能不能少按几个键？文字写错了，能不能直接修改，不用重新截一张？

所以，最近这些更新，我主要在打磨这些每天都会碰到的操作。

现在的 LibreShot，安装包仍然只有约 **1.9 MB**，依然免费，也多了一些可以按自己习惯调整的功能。

## 1. 工具栏，按自己的习惯来

每个人截图的习惯不一样。

有人经常画箭头，有人只想圈个重点，也有人每次都要遮住姓名、账号，再把图片发出去。

如果每次都要在一长排按钮里找工具，多少有点费事。

现在，LibreShot 的工具栏可以自己调整：

- **常用的放前面**：调整工具顺序，把箭头、文字或者马赛克放到顺手的位置。
- **不用的先藏起来**：选择显示或隐藏工具，让工具栏更清爽；需要时再打开。
- **截图后先用什么，也能自己选**：可以默认进入“选择和移动”，也可以换成自己最常用的标注工具。

比如，我想先看看截图范围，再决定怎么标注，就把默认工具设成“选择和移动”。如果你每次截图都是为了画箭头，也可以直接把箭头设成默认工具。

调整一次，后面就按自己的习惯来用。

> 【配图 2｜工具栏前后对比】同一张示例图，上方展示完整工具栏，下方展示只保留选择、箭头、文字、马赛克等常用按钮的工具栏。旁边或下一张小图附“工具栏设置”局部，展示排序、显示勾选和默认工具选项。配文：“常用的放前面，不常用的藏起来。”

## 2. 开始截图，少一点操作

原来的截图快捷键还在：

- 区域截图：`Command + Shift + X`
- 全屏截图：`Command + Shift + A`

如果和你常用的软件冲突，或者你有自己的习惯，也可以在设置里换成其他组合。

这次还加了一个我觉得挺顺手的入口：**双击 Option 键启动区域截图。**

开启之后，轻按两下 Option，就能开始框选。临时想截一小块内容时，不用先去找菜单，也不用记一个组合键。

这个功能可以自行开启或关闭。首次开启，需要按系统提示允许“输入监控”权限。

截图完成后的操作，也可以按习惯调整。例如，开启自动保存后，点击完成会同时复制截图，并保存到指定文件夹；编辑时还可以选择让空格键用于完成截图，或者保存并复制。

这些都是可选设置，不需要一次全部开启，挑自己常用的就好。

> 【配图 3｜双击 Option 演示】建议做一段短动图：画面角落标注“轻按两下 Option”，随后出现截图遮罩、框选一块区域、进入工具栏。若用静态图，可排成三步：“双击 Option → 框选范围 → 开始标注”。不要只放快捷键设置页，重点展示它实际怎么用。

## 3. 标注完了，还能接着调整

有时候，截图本身没问题，只是箭头放歪了、文字写错了，或者几个步骤的编号需要调整。

现在，这些内容都可以接着改。

鼠标移到已有标注可以选中的位置时，会出现手型提示。点一下选中，就能移动到合适的位置。矩形和圆形从边框选中，选中后也能调整大小。

**文字可以直接拖动，写错了就双击修改。** 不用因为一句说明的位置不合适，就重新截一张。

序号也更适合拿来写步骤说明：

- 双击序号，可以修改数字，也可以重新从 1 开始编号。
- 可以调整大小和颜色，让重点更清楚。
- 改成某个数字后，下一次接着往下编号。
- 后面的序号会沿用最近使用的大小和颜色，不必一个个重新设置。

比如给同事说明某个操作，把要点击的地方标成 1、2、3，再加一句文字，一张图就能讲清楚。

> 【配图 4｜标注修改演示】用虚构的三步操作界面做示例，演示“拖动已有文字 → 双击改一句说明 → 修改或缩放序号”。建议做 6–10 秒短动图，动作放慢一些。如果用静态图，放修改前后的两张对比图，并标出改动位置。配文：“标错了，接着改，不用重新截。”

## 4. 打码，可以一笔接着一笔

发截图之前，经常还要处理一下姓名、账号、手机号，或者不想公开的聊天内容。

LibreShot 的马赛克和模糊，现在都支持两种方式：

**涂抹**：像用画笔一样，划到哪里就处理哪里。松手后可以直接继续补涂，不用先点一下空白处。

**框选**：拉出一个矩形，一次处理整片区域。整行账号或者一块聊天内容，用这种方式比较方便。

两种方式都能一边拖动、一边看到效果，再根据内容调整涂抹大小、马赛克颗粒或者模糊强度。

这轮也调整了马赛克和模糊的效果，让日常遮盖信息时更好控制。

处理完后，记得检查一下结果。重要信息要遮到看不清，不能只看整体效果是否好看。

> 【配图 5｜两种打码方式】准备包含虚构姓名、账号的示例图，绝对不要使用真实敏感信息。展示“连续涂抹两次”和“框选整行”两种效果。可以做静态对比：原图、马赛克、模糊三栏，配文：“零散内容用涂抹，整片内容用框选。”如需展示实时变化，也可用这张动图替换配图 4，控制全文动图数量。

## 5. 一页放不下，就截成长图

网页、文档、长列表，一屏经常装不下。

现在可以用 LibreShot 把这些内容截成长图：框好要保存的区域，慢慢向下滚动，完成后按回车结束。

生成长图之后，还能继续加箭头、文字和序号，把重点标出来，再复制或保存。

比如保存一份教程，或者把一段操作流程发给别人，就不用拆成好几张图片。

最近也改善了滚动时短暂往回看的处理。不过，长截图仍建议慢慢滚动，让前后画面保留足够的重叠；复杂页面截完之后，检查一下有没有遗漏。

> 【配图 6｜有标注的长图成品】选择一份公开教程或自制文档，左边展示普通窗口只能看到的一屏，右边展示长截图成品，并在成品上添加两三个说明。不要把整张长图缩成看不清文字的细条，可以展示上、中、下三个局部。配文：“一屏放不下的内容，也能保存下来继续标注。”

## 小巧、免费，内容在本机处理

功能慢慢补齐了，但 LibreShot 仍然是一款小工具。

目前这一版的安装包约 **1.9 MB**。这里说的是下载文件的大小，不是运行时占用的内存。

它依然免费开源，不需要注册账号。日常截图、标注和图片中的文字识别，都在本机完成，无需上传截图，断开网络也能使用。

之前介绍过的文字识别和贴图置顶也都保留着：图里的文字可以提取后复制，截图可以固定在屏幕上，方便一边看、一边操作。

如果需要翻译，还可以翻译识别出的文字，或者把译文放回图片对应的位置。翻译需要 **macOS 26 或更新版本**，首次下载所需语言包需要联网，下载后可以离线使用。背景简单的文档和界面更适合原图翻译，重要内容建议核对一下。

打开下载页面、查看更新也需要网络。因此，更准确地说，LibreShot 的日常截图处理不依赖联网，截图、识别和翻译内容在本机处理。

## 下载和第一次使用

LibreShot 支持 **macOS 13 及以上版本**，可以用于 Apple 芯片和 Intel 芯片的 Mac。

前往 GitHub 下载最新的 `.dmg` 安装包，打开后把 LibreShot 拖到“应用程序”文件夹里。

首次截图，需要在“系统设置 → 隐私与安全性”里允许它录制屏幕；开启双击 Option 时，还需要输入监控权限。这两项是系统管理的权限，按提示开启后退出并重新打开应用即可。

如果系统提示不能直接打开，或者升级后授权开关已经开启却仍不能截图，可以按下载页面附带的安装与授权说明处理。
