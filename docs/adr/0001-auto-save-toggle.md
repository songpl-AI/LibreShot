# ADR 0001：自动保存采用设置开关，而非移除保存按钮

- 状态：已采纳
- 日期：2026-08-29

## 背景

Issue #1 提出「自动保存，去掉保存按钮」。字面做法是移除保存入口、出图即保存。

## 决策

实现为「设置开关」：默认开启自动保存到预设目录，但同时保留一个「另存为」入口（区域截图工具栏、长截图预览窗口各一个），并保留「保存位置」设置项供用户指定目录。

## 为什么

- 截图用户常有「本次存到指定目录 / 换名」的真实需求；彻底移除保存按钮会牺牲该能力。
- 自动保存目录默认 `~/Pictures`，用户可改，避免文件散落。
- 开关默认开，满足原 issue「简化操作」的诉求；关闭后可回到旧的手动保存行为，改动可逆。

## 权衡

- 用「另存为」替代「去掉保存按钮」，界面多一个按钮，但换来可逆性与灵活性。
- 自动保存失败（目录不可写、无权限）需静默降级到保存面板或报错，处理上比纯手动保存多一条分支。

## 2026-10-03：沙盒目录授权恢复

默认 Pictures 路径本身不提供沙盒授权。实际写入遇到权限拒绝时提示用户选择目录，持久化 security-scoped bookmark，再用同一份 PNG 重试一次。重启后继续使用该授权；取消保留已复制截图，其他写入错误继续报告。验证见 [目录授权记录](../qa/save-permission-20261003.md)。
